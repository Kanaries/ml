## Module overview

Many machine learning algorithms, custom feature transforms, and interactive math visualizations require a handful of fundamental matrix primitives—transposing feature tables, computing determinants, row-reducing linear systems, or inverting small covariance/design matrices—without pulling in a multi-megabyte linear algebra bundle or WebAssembly binary.

The **`Algebra`** module exposes `@kanaries/ml`'s built-in pure-JavaScript dense matrix helpers operating directly on native `number[][]` 2D arrays.

## JavaScript implementation

Import matrix utilities from `import { Algebra } from '@kanaries/ml'` in both browser and Node.js applications. Every function is side-effect-safe for common downstream numeric code and returns plain JavaScript arrays (or `false` when an elimination or inverse encounters a singular matrix with no valid pivot).

## Quick start example

```ts
import { Algebra } from '@kanaries/ml';

const A = [[1, 2], [3, 4]];
const AT = Algebra.transpose(A);
const determinant = Algebra.det(A);
const inverse = Algebra.Inverse.elementary(A);
console.log({ AT, determinant, inverse });
```

## Detailed API reference

| Function | Signature | Description |
| --- | --- | --- |
| `Algebra.transpose` | `(matrix: number[][]) => number[][]` | Swaps rows and columns of a rectangular 2D matrix. |
| `Algebra.identityMatrix` | `(A: number[][]) => number[][]` | Creates an identity matrix matching the dimensions of square matrix `A`. |
| `Algebra.augmentMatrix` | `(matrix: number[][], expanded: number[][]) => number[][]` | Concatenates two matrices with matching row counts horizontally (`[A \| B]`). |
| `Algebra.gaussianElimination` | `(A: number[][]) => number[][] \| false` | Reduces a matrix to row-echelon form; returns `false` if singular. |
| `Algebra.cofactorMatrix` | `(matrix: number[][], minorRow: number, minorCol: number) => number[][]` | Returns the submatrix obtained by removing `minorRow` and `minorCol`. |
| `Algebra.det` | `(matrix: number[][]) => number` | Computes the determinant of a non-empty square matrix. |
| `Algebra.Inverse.elementary` | `(A: number[][]) => number[][] \| false` | Computes `A⁻¹` via Gauss-Jordan elimination on `[A \| I]`; returns `false` if non-invertible. |

### Usage notes

- Always check `if (inv === false)` before using results from `gaussianElimination` or `Inverse.elementary` on user-supplied matrices that may be rank-deficient.
- For large sparse feature matrices, use [`CSRMatrix`](/docs/apis/data); for descriptive statistics, see [`KMath`](/docs/apis/KMath).
