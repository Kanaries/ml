## Algorithm overview

Regression targets in real applications—prices, session durations, order totals, exponential growth metrics—are often strictly positive and strongly right-skewed. Fitting ordinary least squares directly on raw skewed values lets a few extreme high targets dominate squared error and can even produce negative predictions.

**TransformedTargetRegressor** wraps any base regressor with an **invertible target transformation**: it transforms `y` (for example with `log1p`) before fitting the inner regressor, and automatically applies the exact inverse (`expm1`) inside `predict()` so outputs return cleanly in original business units—eliminating manual back-transformation bugs across training, cross-validation, and production serving.

## JavaScript implementation

`Compose.TransformedTargetRegressor` runs in pure TypeScript across browsers and Node.js. It clones both the base `regressor` and `transformer` before fitting, supports nested `regressor__param` and `transformer__param` addressing in `setParams()` (making it tunable inside `GridSearchCV`), and serializes cleanly via `toJSON()` / [`loadModel()`](/docs/apis/serialization) when using named `FunctionTransformer` transforms (`'log1p'` / `'expm1'`, `'sqrt'` / `'square'`, scalers, etc.).

## Quick start

```ts
import { Compose, Linear, utils } from '@kanaries/ml';

const model = new Compose.TransformedTargetRegressor({
  regressor: new Linear.LinearRegression(),
  transformer: new utils.Preprocessing.FunctionTransformer({
    func: 'log1p',
    inverseFunc: 'expm1',
  }),
});

model.fit([[0], [1], [2]], [1, 3, 7]);
console.log(model.predict([[3]])); // approximately [15]
```

## Detailed API reference

- **`new Compose.TransformedTargetRegressor({ regressor?, transformer?, func?, inverseFunc? })`** — defaults to `LinearRegression` and identity transform. Supply either `transformer` (recommended for JSON serialization) or a `func` / `inverseFunc` pair (mutually exclusive).
- **`fit(X, y)` / `predict(X)` / `score(X, y)`** — `score` computes R² in the **original untransformed** target space.
