## Algorithm overview

Classical sample mean and covariance have a breakdown point of zero: a single extreme outlier can drag the mean and stretch the covariance matrix arbitrarily far. **Minimum Covariance Determinant (`MinCovDet`)** finds the subset of `h` observations (at least half the dataset) whose empirical covariance matrix has the **smallest determinant**, yielding a high-breakdown robust estimate of multivariate center (`location`) and spread (`covariance`).

`@kanaries/ml` implements the **FAST-MCD** algorithm (Rousseeuw & Van Driessen): random elemental starts, iterative concentration steps (C-steps) that monotonically reduce the determinant, Gaussian consistency scaling, and chi-square distance reweighting (`support`) to recover high statistical efficiency without sacrificing outlier resistance.

## JavaScript implementation

`Covariance.MinCovDet` runs entirely in pure TypeScript across browsers and Node.js—powering both direct robust Mahalanobis scoring and [`Covariance.EllipticEnvelope`](/docs/apis/covariance/ellipticEnvelope). Because FAST-MCD performs repeated `p × p` covariance inversions across C-steps, it is best suited for small-to-moderate feature widths (`p ≤ 30`) and tabular browser datasets; for large jobs, run inside a Web Worker. Fitted models serialize via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Covariance } from '@kanaries/ml';

const X = [[0, 0], [0.1, 0.2], [0.2, 0.1], [-0.1, 0], [8, 8]];
const robust = new Covariance.MinCovDet({ supportFraction: 0.8, randomState: 42 });
robust.fit(X);

console.log({
  location: robust.location,
  support: robust.support,
  mahalanobis: robust.mahalanobis(X),
});
```

## Detailed API reference

### `new Covariance.MinCovDet(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `supportFraction` | `number` | `(n + p + 1) / (2n)` | Proportion of samples in `(0, 1]` used in the raw MCD subset. Lower values tolerate higher outlier contamination (up to ~50%). |
| `assumeCentered` | `boolean` | `false` | If `true`, assumes data is already centered at the origin and estimates scatter only. |
| `randomState` | `number` | `undefined` | Seed for reproducible elemental subsampling. |

### Methods & properties

- `fit(X: number[][]): void` — computes raw FAST-MCD and chi-square reweighted estimates.
- `mahalanobis(X: number[][]): number[]` — returns squared robust Mahalanobis distances `(x - μ)ᵀ Σ⁻¹ (x - μ)`.
- Reweighted properties: `location`, `covariance`, `precision`, `support` (boolean inlier mask).
- Raw pre-reweighting properties: `rawLocation`, `rawCovariance`, `rawSupport`.
