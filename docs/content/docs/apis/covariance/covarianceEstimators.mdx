## Algorithm overview

When estimating a `p × p` covariance matrix from `n` observations, the maximum-likelihood empirical covariance becomes noisy—or outright singular—whenever `p` is not tiny compared to `n`. **Shrinkage covariance** and **sparse inverse covariance** solve this conditioning problem in complementary ways:

- **`EmpiricalCovariance`**: standard maximum-likelihood covariance and precision matrix for clean datasets where `n >> p`.
- **`ShrunkCovariance`**: blends the empirical covariance toward a scaled identity matrix with a user-chosen `shrinkage` weight in `[0, 1]`.
- **`LedoitWolf`**: computes the analytically optimal L2 shrinkage weight minimizing expected Frobenius error without cross-validation.
- **`OAS` (Oracle Approximating Shrinkage)**: tightens Ledoit-Wolf shrinkage under Gaussian assumptions, often achieving lower estimation error when `p` is large relative to `n`.
- **`GraphicalLasso`**: adds an L1 penalty (`alpha`) to the **inverse covariance (precision) matrix** via block coordinate descent, driving weak partial correlations to zero to uncover sparse conditional-independence graphs.

## JavaScript implementation

All five estimators live under `import { Covariance } from '@kanaries/ml'` in pure TypeScript for browser and Node.js applications. Every estimator exposes `location`, `covariance`, `precision`, and `mahalanobis(X)` distances, and serializes via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start

```ts
import { Covariance } from '@kanaries/ml';

const X = [[0, 1], [1, 0], [2, 1], [3, 2], [2, 3]];
const oas = new Covariance.OAS();
oas.fit(X);
console.log({
  shrinkage: oas.shrinkageValue,
  covariance: oas.covariance,
  mahalanobis: oas.mahalanobis([[1, 1]]),
});
```

## Detailed API reference

### Estimators & options

| Class | Options | Key properties |
| --- | --- | --- |
| `EmpiricalCovariance` | `{ assumeCentered?: boolean }` | `location`, `covariance`, `precision` |
| `ShrunkCovariance` | `{ shrinkage?: number (0.1), assumeCentered?: boolean }` | `location`, `covariance`, `precision` |
| `LedoitWolf` | `{ assumeCentered?: boolean }` | `location`, `covariance`, `precision`, `shrinkageValue` |
| `OAS` | `{ assumeCentered?: boolean }` | `location`, `covariance`, `precision`, `shrinkageValue` |
| `GraphicalLasso` | `{ alpha?: number (0.01), maxIter?: number (100), tol?: number (1e-4), enetTol?: number (1e-4), assumeCentered?: boolean }` | `location`, `covariance`, `precision`, `nIter` |

### Shared methods

- `fit(X: number[][]): void` — estimates mean (`location`), covariance, and inverse covariance (`precision`).
- `mahalanobis(X: number[][]): number[]` — computes squared Mahalanobis distances using `precision`.
