## Algorithm overview

Standard scaling and one-hot encoding break down on three common tabular feature patterns:

- **Smooth nonlinear numeric curves**: [`SplineTransformer`](#splinetransformer) expands each numeric column into piecewise-polynomial **B-spline basis functions**, letting linear models ([Ridge](/docs/apis/linear/ridgeRegression), [LogisticRegression](/docs/apis/linear/logisticRegression)) capture flexible smooth curves without the wild boundary oscillations of high-degree global polynomials.
- **High-cardinality categoricals** (postal codes, product SKUs, user segments): one-hot encoding explodes feature width, whereas [`TargetEncoder`](#targetencoder) replaces each category with a smoothed empirical target mean—using **internal cross-fitting** during `fitTransform()` to prevent target leakage.
- **Multi-label tag arrays** (`['search', 'ml']`): [`MultiLabelBinarizer`](#multilabelbinarizer) converts variable-length label sets into fixed binary indicator matrices (`number[][]` or sparse [`CSRMatrix`](/docs/apis/data)).

## JavaScript implementation

`@kanaries/ml` exports `utils.SplineTransformer`, `utils.TargetEncoder`, and `utils.MultiLabelBinarizer` in pure TypeScript for browser and Node.js pipelines. All three integrate seamlessly with [`Pipeline`](/docs/apis/pipeline) and serialize cleanly via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start

```ts
import { utils } from '@kanaries/ml';

const spline = new utils.SplineTransformer({ nKnots: 4, degree: 3 });
const curved = spline.fitTransform([[0], [1], [2], [3]]);

const encoder = new utils.TargetEncoder({ smooth: 2, cv: 3 });
const encoded = encoder.fitTransform(
  [['free'], ['pro'], ['free'], ['team'], ['pro'], ['team']],
  [2, 12, 4, 20, 10, 22],
);

const labels = new utils.MultiLabelBinarizer();
const indicators = labels.fitTransform([['search', 'ml'], ['charts'], []]);
console.log({ curved, encoded, indicators });
```

## Detailed API reference

### `SplineTransformer`

Accepts `nKnots`, `degree`, `knots` (`'uniform'`, `'quantile'`, or explicit per-feature knot arrays), `extrapolation`, and `includeBias`.

### `TargetEncoder`

Accepts `categories`, `targetType` (`'auto'`, `'continuous'`, or `'binary'`), `smooth`, `cv`, `shuffle`, and `randomState`. During `fitTransform(X, y)`, out-of-fold cross-fitting keeps each sample's own target out of its encoded value; during `transform(XTest)`, unseen categories safely fall back to the global training target mean.

### `MultiLabelBinarizer`

Accepts optional ordered `classes` and `sparseOutput: boolean`. Exposes `fit`, `transform`, `fitTransform`, `inverseTransform`, and fitted `classes`.
