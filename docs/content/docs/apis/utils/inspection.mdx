## Algorithm overview

Accuracy metrics tell you *how well* a model performs, but product teams, auditors, and analysts need to know *why* it predicts what it does. **Model-agnostic inspection** works identically across linear models, trees, ensembles, SVMs, k-NN, and full [`Pipeline`](/docs/apis/pipeline) objects without relying on estimator internals:

- **`permutationImportance`**: measures how much a fitted model's validation score drops when a single feature column is randomly shuffled across rows (repeated `nRepeats` times for mean and standard deviation). Unlike tree impurity importance—which biases toward high-cardinality numeric columns and evaluates training data—permutation importance runs cleanly on **held-out test sets**.
- **`partialDependence` (PDP)**: evaluates how average predictions change as one feature (1D curve) or two features (2D surface) sweep across a quantile grid while keeping all other columns at their observed values.

## JavaScript implementation

`@kanaries/ml` exposes `utils.permutationImportance` and `utils.partialDependence` in pure TypeScript for browser dashboards and Node.js analytics jobs—making it straightforward to render live feature-importance bar charts and PDP response curves alongside client-side models.

## Quick start

```ts
import { Linear, utils } from '@kanaries/ml';

const X = [[0, 0], [1, 0], [2, 1], [3, 1]];
const y = [0, 2, 4, 6];
const model = new Linear.LinearRegression();
model.fit(X, y);

const importance = utils.permutationImportance(model, X, y, {
  nRepeats: 10,
  randomState: 42,
});
const dependence = utils.partialDependence(model, X, [0], {
  gridResolution: 20,
});
console.log({ importancesMean: importance.importancesMean, gridLen: dependence.gridValues[0].length });
```

## Detailed API reference

- **`utils.permutationImportance(estimator, X, y, { nRepeats = 5, randomState?, scoring? })`** — returns `{ importances: number[][], importancesMean: number[], importancesStd: number[] }`. Always pass a held-out validation/test set to measure true generalization importance.
- **`utils.partialDependence(estimator, X, features, { gridResolution = 100, percentiles = [0.05, 0.95] })`** — accepts 1 or 2 column indices (`[col]` or `[colA, colB]`) and returns `gridValues` and averaged predictions matching the grid shape.
