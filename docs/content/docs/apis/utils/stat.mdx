## Algorithm overview

Decision trees, split-quality diagnostics, and exploratory data checks all rely on a core set of fast summary and impurity functions:

- **Central tendency (`mode`, `mean`)**: compute the most frequent discrete value or arithmetic mean of a numeric vector.
- **Distribution conversion (`freqs2Probs`)**: normalize non-negative frequency counts into a probability distribution summing to `1`.
- **Node impurity (`entropy`, `gini`)**: quantify class uncertainty inside a group of counts—Shannon entropy (`-Σ p log₂ p`) and Gini impurity (`1 - Σ p²`) are the exact split criteria used inside [`Tree.DecisionTreeClassifier`](/docs/apis/tree/decisionTreeClassifier).

## JavaScript implementation

`@kanaries/ml` exposes these zero-dependency helpers under `utils.Stat` for both browser and Node.js codebases, so custom tree diagnostics, interactive educational demos, and data-profiling panels can share the same tested math routines used internally by the library.

## Quick start example

```ts
import { utils } from '@kanaries/ml';

const majority = utils.Stat.mode([1, 1, 2, 3]);
const avg = utils.Stat.mean([1, 2, 3]);
const probs = utils.Stat.freqs2Probs([2, 2, 4]);
const entropy = utils.Stat.entropy([2, 2, 4]);
const gini = utils.Stat.gini([2, 2, 4]);
console.log({ majority, avg, probs, entropy, gini });
```

## Detailed API reference

| Function | Signature | Description |
| --- | --- | --- |
| `utils.Stat.mode` | `(data: number[]) => number` | Returns the most frequent numeric value in `data`. |
| `utils.Stat.mean` | `(data: number[]) => number` | Returns the arithmetic mean of `data`. |
| `utils.Stat.freqs2Probs` | `(freqs: number[]) => number[]` | Normalizes a count vector by its sum into probabilities in `[0, 1]`. |
| `utils.Stat.entropy` | `(data: number[]) => number` | Converts frequency counts to probabilities and returns Shannon entropy. |
| `utils.Stat.gini` | `(data: number[]) => number` | Converts frequency counts to probabilities and returns Gini impurity `1 - Σ pᵢ²`. |
