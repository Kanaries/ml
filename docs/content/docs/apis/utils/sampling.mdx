## Algorithm overview

Honest model evaluation always starts by holding out unseen test data before fitting scalers, selectors, or estimators. **Sampling utilities** let you partition paired feature matrices `X` and target vectors `y` into reproducible training and test splits (`trainTestSplit`) or draw random samples without replacement (`std`) directly from standard JavaScript arrays.

Because `trainTestSplit` accepts a deterministic `randomState` seed, experiments across browser sessions, CI tests, and Node.js training jobs evaluate on the exact same holdout split every time.

## JavaScript implementation

`@kanaries/ml` exports generic sampling helpers under `utils.Sampling`. Because both helpers operate on generic TypeScript arrays (`X[]`, `Y[]`), you can split raw `string[]` text corpora, structured objects, or numeric `number[][]` matrices with full type preservation.

## Quick start example

```ts
import { utils } from '@kanaries/ml';

const X = [[0], [1], [2], [3], [4]];
const y = [0, 0, 1, 1, 1];

const split = utils.Sampling.trainTestSplit(X, y, {
  testSize: 0.4,
  randomState: 42,
});

const sample = utils.Sampling.std([1, 2, 3, 4, 5], 3);
console.log({ split, sample });
```

## Detailed API reference

### `utils.Sampling.trainTestSplit(X, y?, options?)`

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `testSize` | `number` | `0.25` | Fraction in `(0, 1)` or exact integer count of held-out rows. |
| `shuffle` | `boolean` | `true` | Randomly permute indices before splitting (`false` keeps temporal order for time-series holdouts). |
| `randomState` | `number` | `undefined` | Seed for deterministic shuffling. |

Returns `{ XTrain, XTest, yTrain?, yTest? }`.

### `utils.Sampling.std(arr, size)`

Returns a uniform random sample of length `size` drawn **without replacement**. If `size >= arr.length`, returns a shallow copy.

### When to use K-Fold or Group Splitters

- For robust hyperparameter tuning or small datasets, prefer K-Fold / Stratified K-Fold in [`utils.ModelSelection`](/docs/apis/utils/modelSelection).
- When multiple rows share a user, patient, or session ID, prevent entity leakage with [`GroupShuffleSplit` or `StratifiedGroupKFold`](/docs/apis/utils/groupSplitters).
