## Algorithm overview

Raw tabular inputs rarely enter a machine learning estimator unchanged. Distance-based models ([K-Means](/docs/apis/clusters/kmeans), [k-NN](/docs/apis/neighbors/knn), [DBSCAN](/docs/apis/clusters/dbscan)) and regularized linear models ([Ridge](/docs/apis/linear/ridgeRegression), [Lasso](/docs/apis/linear/lassoRegression), [SVC](/docs/apis/svm/SVC)) degrade sharply when one column spans `[0, 100000]` while another sits in `[0, 1]`. Categorical strings must be encoded numerically, missing values must be imputed, and zero-variance columns should be removed before fitting.

`utils.Preprocessing` provides scikit-learn-style fit/transform preprocessors that learn training statistics once and replay them identically on validation and production inputs—preventing train/test leakage when wrapped inside a [`Pipeline`](/docs/apis/pipeline) or [`ColumnTransformer`](/docs/apis/pipeline/column-transformer).

## JavaScript implementation

All scalers, normalizers, encoders, `SimpleImputer`, `VarianceThreshold`, and `SelectKBest` live under `import { utils } from '@kanaries/ml'` in pure TypeScript for browser and Node.js runtimes, and serialize cleanly via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { utils } from '@kanaries/ml';

const scaler = new utils.Preprocessing.StandardScaler();
const scaled = scaler.fitTransform([[1, 10], [2, 20], [3, 30]]);

const encoder = new utils.Preprocessing.OneHotEncoder({ drop: 'ifBinary' });
const encoded = encoder.fitTransform([
  ['red', 'S'],
  ['blue', 'M'],
]);
console.log({ scaled, encoded });
```

## Detailed API reference

### Scalers & normalizers

| Class | Options | Methods |
| --- | --- | --- |
| `StandardScaler` | `{ withMean = true, withStd = true }` | `fit`, `transform`, `fitTransform`, `inverseTransform` |
| `MinMaxScaler` | `{ featureRange = [0, 1] }` | `fit`, `transform`, `fitTransform`, `inverseTransform` |
| `MaxAbsScaler` | none | `fit`, `transform`, `fitTransform`, `inverseTransform` |
| `Normalizer` | `{ norm = 'l2' }` (`'l1' \| 'l2' \| 'max'`) | `fit` (no-op), `transform`, `fitTransform` |

### Encoders, imputation & filtering

- **Encoders**: `LabelEncoder()` (numeric class labels), `OrdinalEncoder()`, `OneHotEncoder({ drop?: 'none' | 'first' | 'ifBinary' })`, and `Binarizer({ threshold?: number })`.
- **Simple imputation**: `SimpleImputer({ strategy?: 'mean' | 'median' | 'mostFrequent' | 'constant', fillValue?, missingValues? })`. For correlated numeric columns, see [`Impute.IterativeImputer`](/docs/apis/impute/iterativeImputer).
- **Filtering**: `VarianceThreshold({ threshold?: number })`, `fRegression(X, y)`, and `SelectKBest({ k?: number, scoreFunc? })`.
- **Related pages**: [Advanced Preprocessing (Splines & TargetEncoder)](/docs/apis/utils/advancedPreprocessing), [ML Pipelines](/docs/apis/pipeline), [ColumnTransformer](/docs/apis/pipeline/column-transformer).
