## Algorithm overview

Ordinary least squares minimizes squared residuals, so even one corrupted sensor reading, typo, or extreme transaction can tilt the entire fitted slope dramatically. **Robust regression** estimators limit or eliminate the influence of outliers—or target conditional quantiles instead of conditional means:

| Estimator | How it resists outliers | Best when |
| --- | --- | --- |
| `HuberRegressor` | Switches from quadratic loss to linear loss beyond `epsilon * scale` | Moderate `y`-outliers and you want fast smooth optimization |
| `RANSACRegressor` | Repeatedly fits minimal subsets and keeps the largest consensus inlier set | Severe gross outliers (`20%–40%` bad rows) in `y` |
| `TheilSenRegressor` | Computes the spatial median across many subsample slopes | Small-to-medium datasets with outliers in both `X` and `y` |
| `QuantileRegressor` | Minimizes asymmetric pinball loss (L1 at `quantile: 0.5`) via ADMM | Median regression or prediction intervals (for example 10th & 90th percentiles) |

## JavaScript implementation

`@kanaries/ml` provides `Linear.HuberRegressor`, `Linear.RANSACRegressor`, `Linear.TheilSenRegressor`, and `Linear.QuantileRegressor` in pure TypeScript for browser and Node.js apps. All four expose scikit-learn-style `fit`/`predict` APIs, integrate inside [`Pipeline`](/docs/apis/pipeline), and serialize cleanly via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start

```ts
import { Linear } from '@kanaries/ml';

const model = new Linear.RANSACRegressor({ randomState: 42 });
model.fit([[0], [1], [2], [3]], [0, 1, 20, 3]);
console.log(model.predict([[4]]), model.inlierMask);
```

## Detailed API reference

- **`Linear.HuberRegressor({ epsilon = 1.35, alpha = 0.0001, maxIter = 100, tol = 1e-5, fitIntercept = true })`** — smaller `epsilon` (minimum `1.0`) increases robustness; exposes `coef`, `intercept`, `scale`, and boolean `outliers`.
- **`Linear.RANSACRegressor({ estimator, minSamples, residualThreshold, maxTrials = 100, stopProbability = 0.99, randomState })`** — defaults to `LinearRegression`; exposes `estimatorFitted`, boolean `inlierMask`, and `nTrials`.
- **`Linear.TheilSenRegressor({ nSubsamples, maxSubpopulation = 10000, maxIter = 300, tol = 1e-3, randomState })`** — exposes `coef`, `intercept`, and `nIter`.
- **`Linear.QuantileRegressor({ quantile = 0.5, alpha = 1, fitIntercept = true, maxIter = 5000, tol = 1e-7 })`** — fits any conditional quantile in `(0, 1)` via ADMM; fit `quantile: 0.1` and `quantile: 0.9` to build an 80% prediction interval.
