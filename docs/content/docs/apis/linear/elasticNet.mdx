## Algorithm overview

**ElasticNet** combines the **L1 sparsity penalty** of [Lasso Regression](/docs/apis/linear/lassoRegression) with the **L2 stability penalty** of [Ridge Regression](/docs/apis/linear/ridgeRegression) via a mixing hyperparameter `l1Ratio` in `[0, 1]`.

On real-world tabular datasets with groups of correlated predictors (or more features than rows), pure Lasso can arbitrarily pick one column from a correlated cluster and fluctuate wildly across resamples, while pure Ridge retains every noisy feature. ElasticNet delivers the best of both worlds: it zeros out irrelevant columns like Lasso while keeping correlated informative features together smoothly like Ridge.

## JavaScript implementation

`@kanaries/ml` provides `Linear.ElasticNet` in pure TypeScript for browser and Node.js runtimes. When `l1Ratio === 0`, it delegates directly to `RidgeRegression`; when `l1Ratio === 1`, it delegates to `LassoRegression`; for intermediate values it runs regularized coordinate descent. It integrates cleanly with [`Pipeline`](/docs/apis/pipeline), `GridSearchCV`, and JSON persistence via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Linear } from '@kanaries/ml';

const X = [[0, 1], [1, 1], [2, 0], [3, 0]];
const y = [1, 2, 3, 4];

const model = new Linear.ElasticNet({ alpha: 0.1, l1Ratio: 0.5 });
model.fit(X, y);
const pred = model.predict([[4, 0]]);
console.log(pred);
```

## Detailed API reference

### `new Linear.ElasticNet(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `alpha` | `number` | `1` | Overall regularization multiplier controlling total penalty strength. |
| `l1Ratio` | `number` | `0.5` | Mixing weight in `[0, 1]`. `0` equals pure L2 (Ridge), `1` equals pure L1 (Lasso). |
| `fitIntercept` | `boolean` | `true` | Estimate an unpenalized intercept term. |
| `maxIter` | `number` | `1000` | Maximum coordinate-descent iterations. |
| `tol` | `number` | `1e-6` | Convergence tolerance on coefficient updates. |

### Methods & tuning workflow

- `fit(X: number[][], Y: number[]): void` — fits the combined L1/L2 regression model.
- `predict(X: number[][]): number[]` — generates numeric predictions for `X`.
- **Recommended grid**: Standardize columns with [`StandardScaler`](/docs/apis/utils/preprocessing) inside a [`Pipeline`](/docs/apis/pipeline), then search `l1Ratio` in `[0.1, 0.5, 0.9]` and `alpha` across `[0.001, 0.01, 0.1, 1]`.
- **Related pages**: [Ridge Regression](/docs/apis/linear/ridgeRegression), [Lasso Regression](/docs/apis/linear/lassoRegression), [Robust Regressors](/docs/apis/linear/robustRegressors).
