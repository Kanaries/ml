## Algorithm overview

**Lasso Regression** (Least Absolute Shrinkage and Selection Operator) adds an **L1 penalty** (`alpha * ||w||₁`) to the least-squares regression objective. Because the L1 norm has sharp corners along coordinate axes, soft-thresholding during coordinate descent drives weak or irrelevant feature weights to **exact zero**—performing automatic embedded feature selection alongside regularization.

Use Lasso Regression when:

- Your dataset contains many candidate numeric features but only a subset truly drives the target.
- You want a compact, human-interpretable linear formula with sparse non-zero coefficients.
- You need embedded feature selection inside [`FeatureSelection.SelectFromModel`](/docs/apis/feature_selection/selectors) or a browser-side analytics workflow.

## JavaScript implementation

`@kanaries/ml` provides `Linear.LassoRegression` and its scikit-learn alias `Linear.Lasso`, solved via deterministic coordinate descent in pure TypeScript for browsers and Node.js. It composes with [`Pipeline`](/docs/apis/pipeline), supports `getParams()` / `setParams()` for hyperparameter search, and serializes via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Linear } from '@kanaries/ml';

const X = [[0, 1], [1, 1], [2, 0], [3, 0]];
const y = [1, 2, 3, 4];

const model = new Linear.LassoRegression({ alpha: 0.1, maxIter: 1000, tol: 1e-6 });
model.fit(X, y);
const pred = model.predict([[4, 0]]);
console.log(pred);
```

## Detailed API reference

### `new Linear.LassoRegression(props?)` / `new Linear.Lasso(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `alpha` | `number` | `1` | L1 penalty strength. Larger values push more coefficients to exact zero. |
| `fitIntercept` | `boolean` | `true` | Estimate an unpenalized intercept term. |
| `maxIter` | `number` | `1000` | Maximum coordinate-descent passes. Increase if convergence is slow on small `alpha` or correlated features. |
| `tol` | `number` | `1e-6` | Convergence tolerance on maximum coefficient update per pass. |

### Methods & practical guidance

- `fit(X: number[][], Y: number[]): void` — runs cyclic coordinate descent with soft-thresholding.
- `predict(X: number[][]): number[]` — computes linear predictions from the sparse weights.
- **Standardize features first**: Always pair Lasso with [`StandardScaler`](/docs/apis/utils/preprocessing) inside a [`Pipeline`](/docs/apis/pipeline); unscaled columns receive unequal effective L1 penalties.
- **Highly correlated predictors**: Pure L1 tends to select one arbitrary feature from a correlated group and zero out the rest. Switch to [`Linear.ElasticNet`](/docs/apis/linear/elasticNet) when you want grouped selection with stability.
- **Related pages**: [Ridge Regression](/docs/apis/linear/ridgeRegression), [ElasticNet](/docs/apis/linear/elasticNet), [Feature Selection](/docs/apis/feature_selection).
