## Algorithm overview

**Bayesian linear regression** places conjugate Gaussian–Gamma priors over regression weights and noise precision, automatically estimating regularization strength from the data via empirical Bayes (evidence maximization) instead of requiring manual `alpha` grid searches.

`@kanaries/ml` provides two complementary Bayesian linear regressors:

- **`BayesianRidge`**: places a single isotropic precision `lambda` across all feature weights (analogous to Ridge regression with learned regularization) and returns **predictive standard deviations** (`predictStd`) quantifying epistemic plus noise uncertainty at every test point.
- **`ARDRegression` (Automatic Relevance Determination)**: learns a *separate* precision `lambda_j` for every feature and prunes irrelevant weights whose precision exceeds `thresholdLambda`—producing sparse models with built-in uncertainty estimates.

## JavaScript implementation

Both `Linear.BayesianRidge` and `Linear.ARDRegression` run in pure TypeScript across browser and Node.js runtimes, mirror scikit-learn's `BayesianRidge` and `ARDRegression` hyperparameter families, compose inside [`Pipeline`](/docs/apis/pipeline), and serialize cleanly via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start

```ts
import { Linear } from '@kanaries/ml';

const X = [[0], [1], [2], [3]];
const y = [1, 3, 5, 7];
const model = new Linear.BayesianRidge();
model.fit(X, y);
const mean = model.predict([[4]]);
const standardDeviation = model.predictStd([[4]]);
console.log({ mean, standardDeviation });
```

## Detailed API reference

### Shared constructor options (`BayesianRidge` & `ARDRegression`)

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `maxIter` | `number` | `300` | Maximum empirical-Bayes update iterations. |
| `tol` | `number` | `1e-3` | Convergence tolerance on weight updates. |
| `alpha1` / `alpha2` | `number` | `1e-6` | Gamma prior shape and rate on noise precision `alpha`. |
| `lambda1` / `lambda2` | `number` | `1e-6` | Gamma prior shape and rate on weight precision `lambda`. |
| `fitIntercept` | `boolean` | `true` | Center features and target to estimate an unpenalized intercept. |
| `thresholdLambda` *(ARD only)* | `number` | `1e4` | Precision cutoff above which a feature weight is pruned to `0`. |

### Methods & fitted properties

- `fit(X, y)` — maximizes marginal log-likelihood to learn posterior mean `coef`, posterior covariance `sigma`, noise precision `alpha`, weight precision `lambda`, `intercept`, and iteration count `nIter`.
- `predict(X)` — returns posterior predictive means.
- `predictStd(X)` — returns per-sample predictive standard deviations (ideal for plotting confidence bands in browser dashboards).
