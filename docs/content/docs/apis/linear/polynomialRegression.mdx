## Algorithm overview

**Polynomial Regression** extends linear regression to smooth non-linear curves by transforming each numeric input feature `x` into powers `[x, x², ..., xᵈ]` up to `degree` and fitting an ordinary least-squares model over the expanded basis. Although the resulting prediction curve is non-linear in `x`, the estimation problem remains strictly linear in the polynomial coefficients—meaning it solves rapidly in closed form with zero gradient-descent tuning.

Polynomial regression works best when:

- A scatter plot shows clear curvature (parabolic growth, diminishing returns, saturation) that a straight line underfits.
- You have a low-dimensional numeric problem where degree `2`–`4` captures the domain trend cleanly.
- You want lightweight, interpretable trendlines embedded directly inside browser charts or CSV calculators.

## JavaScript implementation

`@kanaries/ml` provides `Linear.PolynomialRegression` as a self-contained estimator in pure TypeScript for browser and Node.js apps. Rather than manually constructing a separate polynomial basis transformer before fitting, `PolynomialRegression` encapsulates power expansion, fitting, and prediction inside one serializable estimator (`toJSON()` / [`loadModel()`](/docs/apis/serialization)).

## Quick start example

```ts
import { Linear } from '@kanaries/ml';

const X = [[0], [1], [2], [3]];
const y = [1, 2, 5, 10];

const model = new Linear.PolynomialRegression({ degree: 2 });
model.fit(X, y);
const pred = model.predict([[4]]);
console.log(pred);
```

## Detailed API reference

### `new Linear.PolynomialRegression(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `degree` | `number` | `2` | Integer `≥ 1` specifying the highest power per feature (`1` reduces to standard linear regression). |

### Methods

- `fit(X: number[][], Y: number[]): void` — expands each column to powers `1..degree` and fits ordinary least squares with an intercept.
- `predict(X: number[][]): number[]` — applies the same power expansion and returns predicted values.

### Avoiding polynomial overfitting

- **Keep degree low (`2` or `3`) unless cross-validation proves higher degree helps**: High degrees oscillate wildly between points (Runge's phenomenon) and diverge rapidly outside the training range. Read our practical guide on [how to choose polynomial degree](/docs/guides/choose-polynomial-degree) or test interactively in the [Polynomial Regression Calculator](/tools/polynomial-regression-calculator).
- **Scale inputs before high-degree fits**: Large `x` values (like years `2020..2026`) raised to the 4th power cause numerical ill-conditioning; center or standardize `X` with [`StandardScaler`](/docs/apis/utils/preprocessing) first.
- **Related pages**: [Choosing Polynomial Degree Guide](/docs/guides/choose-polynomial-degree), [Polynomial Regression Calculator](/tools/polynomial-regression-calculator), [Ridge Regression](/docs/apis/linear/ridgeRegression).
