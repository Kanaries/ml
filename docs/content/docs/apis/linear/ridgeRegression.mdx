## Algorithm overview

**Ridge Regression** adds an **L2 regularization penalty** (`alpha * ||w||²`) to the ordinary least squares objective. Whenever predictors are strongly correlated (multicollinearity), feature count approaches sample count, or unregularized coefficients explode in magnitude, L2 shrinkage pulls weights smoothly toward zero without forcing them to exactly zero—trading a tiny amount of bias for a substantial drop in prediction variance.

Use Ridge Regression when:

- Numeric features are collinear (for example, overlapping telemetry metrics or polynomial expansions).
- Ordinary least squares (`LinearRegression`) overfits training noise or exhibits wild coefficient swings across cross-validation folds.
- You expect most features to carry small, spread-out contributions rather than a handful of sparse nonzero predictors.

## JavaScript implementation

`@kanaries/ml` provides `Linear.RidgeRegression` along with its scikit-learn alias `Linear.Ridge`. Both run synchronously in pure TypeScript across browsers and Node.js, compose directly inside [`Pipeline`](/docs/apis/pipeline) with [`StandardScaler`](/docs/apis/utils/preprocessing), and serialize cleanly via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Linear } from '@kanaries/ml';

const X = [[0], [1], [2], [3]];
const y = [1, 3, 5, 7];

const model = new Linear.RidgeRegression({ alpha: 0.5, fitIntercept: true });
model.fit(X, y);
const pred = model.predict([[4]]);
console.log(pred);
```

## Detailed API reference

### `new Linear.RidgeRegression(props?)` / `new Linear.Ridge(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `alpha` | `number` | `1` | Non-negative finite L2 penalty strength. Larger values shrink coefficients more aggressively toward zero. |
| `fitIntercept` | `boolean` | `true` | Estimate an unpenalized intercept term (`false` assumes centered data). |

### Methods

- `fit(X: number[][], Y: number[]): void` — solves the closed-form L2-regularized normal equations.
- `predict(X: number[][]): number[]` — predicts continuous targets; throws if unfitted or if feature count mismatches.

### Tuning & comparison tips

- **Scale features before regularizing**: Because L2 penalizes squared coefficient magnitude equally across features, wrap `StandardScaler` and `Ridge` inside a [`Pipeline`](/docs/apis/pipeline) so large-scale columns are not unfairly favored.
- **Ridge vs Lasso vs ElasticNet**: Prefer Ridge when all features matter slightly; switch to [`Linear.LassoRegression`](/docs/apis/linear/lassoRegression) for sparse feature selection or [`Linear.ElasticNet`](/docs/apis/linear/elasticNet) when correlated groups need sparsity.
