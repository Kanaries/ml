## Algorithm overview

Ordinary least squares assumes symmetric Gaussian noise with constant variance across the target range—an assumption that breaks down on **non-negative counts** (website clicks, support tickets, defect counts), **positive right-skewed continuous metrics** (response latency, order value, insurance severity), or **zero-inflated compound totals** (expected claim cost per policy).

**Generalized Linear Models (GLMs)** pair a linear predictor `η = Xw + b` with a link function (such as the log link `μ = exp(η)`) and an exponential-dispersion deviance loss tailored to the target distribution:

| Estimator | Target domain | Variance function `V(μ)` | Typical use case |
| --- | --- | --- | --- |
| `PoissonRegressor` | Non-negative (`y ≥ 0`) | `μ` (`power = 1`) | Event counts, rates, daily conversions |
| `GammaRegressor` | Strictly positive (`y > 0`) | `μ²` (`power = 2`) | Latency, duration, skewed spend amounts |
| `TweedieRegressor` | Depends on `power` | `μ^p` (`p ≤ 0` or `p ≥ 1`) | Compound Poisson–Gamma (`1 < p < 2`) for zero-inflated totals |

## JavaScript implementation

`Linear.PoissonRegressor`, `Linear.GammaRegressor`, and `Linear.TweedieRegressor` in `@kanaries/ml` optimize L2-regularized deviance via damped Newton updates with a guarded line search in pure TypeScript—ensuring strictly positive log-link predictions in browsers and Node.js without external numerical libraries. All three serialize via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Detailed API reference

### Constructor options

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `alpha` | `number` | `1` | L2 penalty strength shrinking non-intercept coefficients. |
| `fitIntercept` | `boolean` | `true` | Estimate an unpenalized intercept term. |
| `maxIter` | `number` | `100` | Maximum Newton iterations. |
| `tol` | `number` | `1e-4` | Convergence tolerance on step size / gradient norm. |
| `power` *(Tweedie only)* | `number` | `0` | Variance power (`0` = Normal, `1` = Poisson, `1 < p < 2` = Compound Poisson-Gamma, `2` = Gamma, `3` = Inverse Gaussian; values in `(0, 1)` are undefined). |
| `link` *(Tweedie only)* | `'auto' \| 'identity' \| 'log'` | `'auto'` | `'auto'` picks `'identity'` for `power <= 0` and `'log'` for `power > 0`. |

### Methods & properties

- `fit(X, y)` / `predict(X)` — trains the GLM and predicts expected target means (strictly positive under log link).
- Exposes fitted `coef`, `intercept`, and `nIter`.
