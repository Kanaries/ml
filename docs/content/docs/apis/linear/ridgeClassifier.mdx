## Algorithm overview

**RidgeClassifier** repurposes L2-regularized [Ridge Regression](/docs/apis/linear/ridgeRegression) for binary and multiclass classification. It encodes target labels into numerical class indicators, solves one closed-form L2-penalized least-squares system per class (one-vs-rest), and predicts the class achieving the highest linear score.

Compared to iterative classifiers such as [Logistic Regression](/docs/apis/linear/logisticRegression) or [LinearSVC](/docs/apis/svm/LinearSVC), `RidgeClassifier` requires no learning-rate schedule or epoch budget and fits rapidly in closed form—making it a fast, low-variance baseline on numeric tabular datasets and standardized feature matrices.

Use `RidgeClassifier` when:

- You want deterministic, closed-form linear classification without tuning optimizer convergence.
- Features are correlated and benefit from L2 coefficient shrinkage (`alpha`).
- You only need hard class labels (or combine with [`Calibration.CalibratedClassifierCV`](/docs/apis/calibration) when calibrated probabilities are required).

## JavaScript implementation

`@kanaries/ml` provides `Linear.RidgeClassifier` in pure TypeScript for browser and Node.js runtimes. It sorts unique numeric class labels ascending, fits one internal `RidgeRegression` per class, integrates cleanly into [`Pipeline`](/docs/apis/pipeline) and [`utils.ModelSelection`](/docs/apis/utils/modelSelection), and serializes via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Linear } from '@kanaries/ml';

const X = [[0, 0], [0, 1], [2, 2], [3, 2]];
const y = [0, 0, 1, 1];

const clf = new Linear.RidgeClassifier({ alpha: 1 });
clf.fit(X, y);
const pred = clf.predict([[1, 1], [3, 3]]);
console.log(pred);
```

## Detailed API reference

### `new Linear.RidgeClassifier(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `alpha` | `number` | `1` | Non-negative L2 regularization strength controlling variance reduction. |
| `fitIntercept` | `boolean` | `true` | Include an unpenalized intercept term per class model. |

### Methods

- `fit(trainX: number[][], trainY: number[]): void` — sorts unique class labels and fits one `RidgeRegression` estimator per class.
- `predict(testX: number[][]): number[]` — evaluates every class score and returns the label with the highest score.

### Practical guidance

- Standardize input columns with [`StandardScaler`](/docs/apis/utils/preprocessing) inside a [`Pipeline`](/docs/apis/pipeline) before sweeping `alpha` across logarithmic values (`0.01`, `0.1`, `1`, `10`, `100`).
- Need calibrated class probabilities out of the box? Compare against [`Linear.LogisticRegression`](/docs/apis/linear/logisticRegression) or [`DiscriminantAnalysis.LDA`](/docs/apis/discriminant-analysis/lda).
- **Related pages**: [Logistic Regression](/docs/apis/linear/logisticRegression), [Ridge Regression](/docs/apis/linear/ridgeRegression), [LinearSVC](/docs/apis/svm/LinearSVC), [Confusion Matrix Calculator](/tools/confusion-matrix-calculator).
