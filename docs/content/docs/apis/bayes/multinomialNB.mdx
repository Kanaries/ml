## Algorithm overview

**Multinomial Naive Bayes (`MultinomialNB`)** is the classic probabilistic classifier for **non-negative count and frequency features**, especially bag-of-words counts and TF-IDF matrices produced from text documents. It models feature occurrences within each class using a multinomial distribution regularized by Laplace/Lidstone additive smoothing (`alpha`), preventing unseen test tokens from collapsing posterior probabilities to zero.

Use `MultinomialNB` when:

- Building fast client-side or Node.js text categorization (spam detection, support ticket routing, topic tagging, sentiment baselines).
- Feature matrices are wide, sparse, and strictly non-negative (such as outputs from [`CountVectorizer`](/docs/apis/feature_extraction/countVectorizer) or [`TfidfVectorizer`](/docs/apis/feature_extraction/tfidfVectorizer)).
- You need millisecond training and instant prediction without tuning gradient descent schedules.

## JavaScript implementation

`@kanaries/ml` provides `Bayes.MultinomialNB` in pure TypeScript for browser and Node.js applications. It accepts both dense `number[][]` and sparse [`CSRMatrix`](/docs/apis/data) inputs, plugs directly after `FeatureExtraction.TfidfVectorizer` inside a [`Pipeline`](/docs/apis/pipeline), and serializes cleanly via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Bayes } from '@kanaries/ml';

const X = [[2, 0, 1], [1, 0, 2], [0, 2, 1], [0, 3, 1]];
const y = [0, 0, 1, 1];

const clf = new Bayes.MultinomialNB({ alpha: 1.0 });
clf.fit(X, y);
const pred = clf.predict([[1, 0, 1], [0, 2, 2]]);
console.log(pred);
```

## Detailed API reference

### `new Bayes.MultinomialNB(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `alpha` | `number` | `1.0` | Additive (Laplace/Lidstone) smoothing parameter (`0` disables smoothing). Smaller values (`0.1`–`0.5`) often improve TF-IDF accuracy. |
| `forceAlpha` | `boolean` | `true` | If `false`, clamps very small `alpha` values to `1e-10` to avoid numerical issues. |
| `fitPrior` | `boolean` | `true` | Learn class priors from training counts (`false` assumes uniform priors across classes). |
| `classPrior` | `number[] \| null` | `null` | Explicit class prior probabilities overriding `fitPrior`. |

### Methods & usage notes

- `fit(X: number[][] | CSRMatrix, y: number[]): void` — estimates smoothed log feature probabilities and class priors. Throws if any feature value is negative.
- `predict(X: number[][] | CSRMatrix): number[]` — returns the maximum-posterior class label per sample.
- **Imbalanced text classes**: When one category dominates your training corpus, compare `MultinomialNB` against [`Bayes.ComplementNB`](/docs/apis/bayes/complementNB), which corrects skewed class-length weights.
- **Related pages**: [ComplementNB](/docs/apis/bayes/complementNB), [TfidfVectorizer](/docs/apis/feature_extraction/tfidfVectorizer), [ML Pipelines](/docs/apis/pipeline), [CSRMatrix](/docs/apis/data).
