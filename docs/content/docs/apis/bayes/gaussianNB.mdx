## Algorithm overview

**Gaussian Naive Bayes (`GaussianNB`)** is a fast generative probabilistic classifier for continuous numeric features. Under the conditional independence ("naive") assumption, each feature within each class is modeled by a one-dimensional Gaussian distribution estimated purely from its class mean and variance. At inference time, Bayes' rule combines the class prior with the sum of per-feature log-likelihoods to pick the most probable class.

GaussianNB is an excellent choice when:

- You want an ultra-fast baseline that fits in a single `O(n * d)` pass with almost zero hyperparameter tuning.
- Training data is small or streaming, where iterative models like SVMs or deep ensembles risk overfitting.
- You need real-time browser classification with tiny serialized JSON artifacts (only per-class means, variances, and priors are stored).

## JavaScript implementation

`@kanaries/ml` exposes `Bayes.GaussianNB` in pure TypeScript for browser and Node.js runtimes. It supports custom class `priors` and scikit-learn's `varSmoothing` stabilizer (which adds a tiny fraction of the largest feature variance to every variance estimate so zero-variance features never cause division by zero). It composes cleanly inside [`Pipeline`](/docs/apis/pipeline), [`Calibration.CalibratedClassifierCV`](/docs/apis/calibration), and serializes via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Bayes } from '@kanaries/ml';

const clf = new Bayes.GaussianNB({ varSmoothing: 1e-9 });
clf.fit([[1.0, 2.0], [1.2, 1.9], [4.0, 4.2], [4.2, 4.0]], [0, 0, 1, 1]);
const pred = clf.predict([[1.1, 2.1], [4.1, 4.1]]);
console.log(pred);
```

## Detailed API reference

### `new Bayes.GaussianNB(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `priors` | `number[] \| null` | `null` | Optional prior probabilities matching the number of fitted classes (in sorted label order). When `null`, priors are estimated from class frequencies. |
| `varSmoothing` | `number` | `1e-9` | Portion of the largest feature variance added to all variances for numerical stability. |

### Methods

- `fit(X: number[][], y: number[]): void` — computes per-class means, variances, and priors in a single pass.
- `predict(X: number[][]): number[]` — predicts the class maximizing log-posterior probability.

### Practical guidance

- **Correlated features**: Because `GaussianNB` assumes diagonal class covariances, strongly correlated features can make its probabilities overconfident. Consider [`DiscriminantAnalysis.LDA`](/docs/apis/discriminant-analysis/lda), [`DiscriminantAnalysis.QDA`](/docs/apis/discriminant-analysis/qda), or [`Calibration.CalibratedClassifierCV`](/docs/apis/calibration).
- **Count or binary features**: Use [`Bayes.MultinomialNB`](/docs/apis/bayes/multinomialNB), [`Bayes.ComplementNB`](/docs/apis/bayes/complementNB), or [`Bayes.BernoulliNB`](/docs/apis/bayes/bernoulliNB) for discrete count or indicator inputs.
