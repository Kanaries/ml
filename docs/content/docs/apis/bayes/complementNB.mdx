## Algorithm overview

**Complement Naive Bayes (`ComplementNB`)** is an adaptation of [`MultinomialNB`](/docs/apis/bayes/multinomialNB) introduced by Rennie et al. specifically to fix the bias that standard Multinomial Naive Bayes suffers on **imbalanced text datasets**. Instead of estimating feature weights from documents *inside* class `c`, `ComplementNB` computes statistics from the **complement of class `c`** (all documents belonging to *other* classes) and optionally L1-normalizes weights (`norm: true`) so longer classes cannot dominate predictions.

Use `ComplementNB` when:

- Class frequencies in your text or count dataset are heavily skewed (for example 90% normal tickets vs 10% urgent escalations).
- You want a drop-in upgrade over `MultinomialNB` on bag-of-words or TF-IDF features with the exact same `O(nnz)` speed.

## JavaScript implementation

`@kanaries/ml` provides `Bayes.ComplementNB` in pure TypeScript for browsers and Node.js. Like `MultinomialNB`, it supports both dense `number[][]` and sparse [`CSRMatrix`](/docs/apis/data) matrices, integrates directly with [`TfidfVectorizer`](/docs/apis/feature_extraction/tfidfVectorizer) inside a [`Pipeline`](/docs/apis/pipeline), and serializes via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Bayes } from '@kanaries/ml';

const X = [[3, 0, 1], [2, 0, 1], [0, 2, 2], [0, 3, 1]];
const y = [0, 0, 1, 1];

const clf = new Bayes.ComplementNB({ alpha: 1.0, norm: false });
clf.fit(X, y);
const pred = clf.predict([[2, 0, 1], [0, 2, 1]]);
console.log(pred);
```

## Detailed API reference

### `new Bayes.ComplementNB(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `alpha` | `number` | `1.0` | Additive smoothing parameter for complement token counts. |
| `forceAlpha` | `boolean` | `true` | Keeps tiny `alpha` values unmodified when `true`; clamps near-zero values to `1e-10` when `false`. |
| `fitPrior` | `boolean` | `true` | Learn class priors from training frequencies (only applied in binary classification, matching scikit-learn). |
| `classPrior` | `number[] \| null` | `null` | Explicit class priors overriding empirical frequencies. |
| `norm` | `boolean` | `false` | When `true`, performs a second L1 normalization of complement feature weights as recommended in the original ComplementNB paper. |

### Methods & tuning tips

- `fit(X: number[][] | CSRMatrix, y: number[]): void` — requires non-negative feature values.
- `predict(X: number[][] | CSRMatrix): number[]` — assigns each sample to the class with minimum complement score.
- Try sweeping `alpha` in `[0.1, 0.5, 1.0]` with `norm: true` vs `false` using [`utils.ModelSelection`](/docs/apis/utils/modelSelection) and compare macro-F1 via [`Metrics.f1Score`](/docs/apis/metrics).
- **Related pages**: [MultinomialNB](/docs/apis/bayes/multinomialNB), [GaussianNB](/docs/apis/bayes/gaussianNB), [TfidfVectorizer](/docs/apis/feature_extraction/tfidfVectorizer).
