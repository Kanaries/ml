## Module overview

Testing machine learning pipelines, benchmarking clustering speed in browsers, building interactive visualizations, and writing deterministic unit tests all require controlled data with known ground-truth structure.

The **`Datasets`** module provides pure-JavaScript ports of scikit-learn's synthetic dataset generators—allowing you to create isotropic Gaussian clusters, interleaving moons, concentric circles, multi-class tabular benchmarks with informative/redundant/noise features, and linear or low-rank regression problems with exact seeded reproducibility (`randomState`).

## JavaScript implementation

Import synthetic generators from `import { Datasets } from '@kanaries/ml'`. Every generator uses a deterministic PRNG and Box-Muller Gaussian sampling, producing plain `number[][]` feature matrices and `number[]` label/target vectors directly usable by every `@kanaries/ml` estimator in browser and Node.js environments—with zero external data downloads.

| Generator | sklearn equivalent | Primary use case |
| --- | --- | --- |
| `Datasets.makeBlobs` | `make_blobs` | Isotropic Gaussian clusters for K-Means, GMM, HDBSCAN |
| `Datasets.makeMoons` | `make_moons` | Two non-linear interleaving half-circles for DBSCAN, kernel SVM, kNN |
| `Datasets.makeCircles` | `make_circles` | Concentric circles for radial/kernel classifiers and spectral clustering |
| `Datasets.makeClassification` | `make_classification` | Configurable multi-class tabular problems with noise, redundancy, and class imbalance |
| `Datasets.makeRegression` | `make_regression` | Controlled linear or low-rank regression with optional ground-truth `coef` |
| `Datasets.makeLowRankMatrix` | `make_low_rank_matrix` | Matrices with bell-shaped singular value profiles for PCA/SVD benchmarks |

## Detailed API reference

### `Datasets.makeBlobs(props?)` → `{ X: number[][], y: number[] }`

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `nSamples` | `number \| number[]` | `100` | Total sample count or explicit per-cluster counts. |
| `nFeatures` | `number` | `2` | Feature width (inferred if explicit `centers` coordinates are passed). |
| `centers` | `number \| number[][]` | `3` | Number of random centers inside `centerBox`, or explicit `[nCenters][nFeatures]` coordinates. |
| `clusterStd` | `number \| number[]` | `1` | Cluster standard deviation (single number or per-cluster array). |
| `centerBox` | `[number, number]` | `[-10, 10]` | Coordinate bounds for randomly placed centers. |
| `shuffle` / `randomState` | `boolean` / `number` | `true` / `undefined` | Shuffle rows and control reproducibility. |

### `Datasets.makeMoons(props?)` & `Datasets.makeCircles(props?)` → `{ X, y }`

- `nSamples`: total count or `[nOuter, nInner]` (default `100`).
- `noise`: Gaussian standard deviation added to coordinates.
- `factor` (`makeCircles` only): inner-to-outer radius scale in `[0, 1)` (default `0.8`).
- `shuffle` (default `true`) and `randomState`.

### `Datasets.makeClassification(props?)` → `{ X, y }`

Supports `nSamples` (`100`), `nFeatures` (`20`), `nInformative` (`2`), `nRedundant` (`2`), `nRepeated` (`0`), `nClasses` (`2`), `nClustersPerClass` (`2`), `weights` (class proportions), `flipY` (`0.01` label noise), `classSep` (`1`), `hypercube` (`true`), `shift` (`0` or `null` for random), `scale` (`1` or `null` for random), `shuffle` (`true`), and `randomState`.

### `Datasets.makeRegression(props?)` → `{ X, y, coef? }`

Supports `nSamples` (`100`), `nFeatures` (`100`), `nInformative` (`min(nFeatures, 10)`), `nTargets` (`1`), `bias` (`0`), `effectiveRank` (switches to low-rank singular-value matrix via `makeLowRankMatrix`), `tailStrength` (`0.5`), `noise` (`0`), `shuffle` (`true`), `coef` (`false` — set `true` to return ground-truth coefficients), and `randomState`.
