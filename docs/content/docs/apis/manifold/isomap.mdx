## Algorithm overview

**Isomap (Isometric Feature Mapping)** is a nonlinear dimensionality-reduction algorithm that preserves global **geodesic distances** measured *along* a curved manifold rather than straight-line Euclidean chords cutting through empty space. It runs in three stages:

1. Construct a `k`-nearest-neighbor graph connecting locally adjacent samples.
2. Compute all-pairs shortest-path (geodesic) distances across the neighborhood graph.
3. Apply classical Multidimensional Scaling (MDS) to embed the geodesic distance matrix into `nComponents` dimensions.

Compared to [t-SNE](/docs/apis/manifold/tsne), Isomap preserves global manifold geometry and supports **out-of-sample `transform(XNew)`** on unseen points via Nyström kernel projection—making it usable both for 2D visualization and as a nonlinear feature extractor inside a [`Pipeline`](/docs/apis/pipeline).

## JavaScript implementation

`Manifold.Isomap` in `@kanaries/ml` runs in pure TypeScript across browsers and Node.js. If the `k`-NN graph breaks into disconnected components, Isomap automatically warns and bridges each component pair at its closest Euclidean samples (matching scikit-learn's recovery path).

**Browser scaling guidance**: Because Isomap builds an `O(n²)` geodesic distance matrix and runs an `O(n³)` shortest-path + eigendecomposition phase, keep interactive browser datasets to a few hundred samples (or offload fitting to a Web Worker). Fitted embeddings serialize via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Manifold } from '@kanaries/ml';

const X = [[0, 0], [1, 0], [2, 1], [3, 1], [4, 2]];
const model = new Manifold.Isomap({ nNeighbors: 2, nComponents: 2 });
const embedding = model.fitTransform(X);
const newPoints = model.transform([[2.5, 1]]);
console.log({ embedding, newPoints });
```

## Detailed API reference

### `new Manifold.Isomap(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nNeighbors` | `number` | `5` | Number of nearest neighbors per node in the neighborhood graph. Too small fractures the graph; too large creates "short-circuit" edges across folds. |
| `nComponents` | `number` | `2` | Target embedding dimensionality. |

### Methods & properties

- `fit(X)` / `fitTransform(X)` / `transform(X)` — fit geodesic manifold embedding and project training or unseen samples.
- Read-only `embedding` (`[nSamples][nComponents]`) and `distMatrix` (`[nSamples][nSamples]` geodesic distances).
- **Related pages**: [Locally Linear Embedding (LLE)](/docs/apis/manifold/lle), [t-SNE](/docs/apis/manifold/tsne), [MDS](/docs/apis/manifold/MDS), [Kernel PCA](/docs/apis/decomposition/kernelPCA).
