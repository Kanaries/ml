## Algorithm overview

Standard [PCA](/docs/apis/decomposition/pca) finds orthogonal linear projections—so if data lies on concentric circles, spirals, or curved manifolds, linear PCA collapses distinct classes right on top of each other. **Kernel PCA** applies the kernel trick to project observations implicitly into a higher-dimensional reproducing kernel Hilbert space (RKHS) and performs eigen-decomposition on the centered `n × n` Gram (kernel) matrix.

Use Kernel PCA when:

- Linear PCA fails to separate curved or concentric clusters before visualization or linear classification.
- You need **out-of-sample `transform(XTest)`** on unseen points (unlike non-parametric embeddings such as [t-SNE](/docs/apis/manifold/tsne)).
- You want optional pre-image reconstruction (`fitInverseTransform: true`) via kernel ridge regression.

## JavaScript implementation

`Decomposition.KernelPCA` in `@kanaries/ml` supports `'linear'`, `'poly'`, `'rbf'`, `'sigmoid'`, and `'cosine'` kernels in pure TypeScript for browser and Node.js workflows. It composes directly inside [`Pipeline`](/docs/apis/pipeline) and serializes via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

**Memory & scaling note**: Because Kernel PCA builds and eigendecomposes an `O(n²)` Gram matrix (`n × n`), keep browser datasets under roughly 1,000–1,500 rows, or approximate RBF kernels at scale with [`Kernel.Nystroem`](/docs/apis/kernel/nystroem) or [`Kernel.RBFSampler`](/docs/apis/kernel/rbfSampler) followed by linear PCA.

## Quick start example

```ts
import { Decomposition } from '@kanaries/ml';

const model = new Decomposition.KernelPCA({
  nComponents: 2,
  kernel: 'rbf',
  gamma: 2,
});
const embedded = model.fitTransform([[1, 0], [0, 1], [-1, 0], [0, -1]]);
console.log(embedded);
```

## Detailed API reference

### `new Decomposition.KernelPCA(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nComponents` | `number \| null` | `null` (all positive eigenvalues) | Number of nonlinear components to retain. |
| `kernel` | `'linear' \| 'poly' \| 'rbf' \| 'sigmoid' \| 'cosine'` | `'linear'` | Kernel function computing pairwise similarity. |
| `gamma` | `number` | `1 / nFeatures` | Kernel coefficient for `'rbf'`, `'poly'`, and `'sigmoid'`. |
| `degree` / `coef0` | `number` | `3` / `1` | Degree and independent offset for `'poly'` and `'sigmoid'` kernels. |
| `fitInverseTransform` / `alpha` | `boolean` / `number` | `false` / `1.0` | Enables kernel-ridge `inverseTransform()` with L2 regularization `alpha`. |
| `randomState` | `number` | `undefined` | Seed for deterministic sign/eigensolver tie-breaking. |

### Methods & properties

- `fit(X)` / `transform(X)` / `fitTransform(X)` / `inverseTransform(X)` (requires `fitInverseTransform: true`).
- `eigenvalues` and `eigenvectors` expose defensive copies of the centered Gram spectrum.
- **Related pages**: [PCA](/docs/apis/decomposition/pca), [Kernel Approximation (`Nystroem` / `RBFSampler`)](/docs/apis/kernel), [Isomap](/docs/apis/manifold/isomap).
