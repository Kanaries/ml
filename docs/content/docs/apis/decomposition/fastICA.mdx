## Algorithm overview

**Independent Component Analysis (FastICA)** separates a multivariate dataset into additive, **statistically independent** latent sources by maximizing non-Gaussianity (approximated via negentropy contrast functions such as `logcosh`, `exp`, or `cube`).

Whereas [PCA](/docs/apis/decomposition/pca) only produces *uncorrelated* orthogonal directions based on second-order covariance, FastICA leverages higher-order statistics to untangle mixed signals—famous for the "cocktail party problem" (separating overlapping audio recordings), removing eye-blink artifacts from EEG/sensor streams, or uncovering independent drivers in multivariate financial and telemetry series.

## JavaScript implementation

`Decomposition.FastICA` in `@kanaries/ml` provides both `'parallel'` (symmetric) and `'deflation'` fixed-point updates in pure TypeScript for browser and Node.js runtimes, with configurable whitening modes (`'unit-variance'`, `'arbitrary-variance'`, or `false`), deterministic `randomState` initialization, forward `transform()`, signal reconstruction via `inverseTransform()`, and JSON serialization (`toJSON()` / [`loadModel()`](/docs/apis/serialization)).

## Quick start example

```ts
import { Decomposition } from '@kanaries/ml';

const observedSignals = [[0, 1], [1, 0], [2, 1], [1, 2], [-1, 0]];
const ica = new Decomposition.FastICA({
  nComponents: 2,
  whiten: 'unit-variance',
  randomState: 0,
});
const sources = ica.fitTransform(observedSignals);
const reconstructed = ica.inverseTransform(sources);
console.log({ sources, reconstructed });
```

## Detailed API reference

### `new Decomposition.FastICA(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nComponents` | `number` | `nFeatures` | Number of independent sources to extract (ignored when `whiten: false`, matching scikit-learn). |
| `algorithm` | `'parallel' \| 'deflation'` | `'parallel'` | `'parallel'` estimates all components simultaneously; `'deflation'` extracts components one by one. |
| `whiten` | `'unit-variance' \| 'arbitrary-variance' \| false` | `'unit-variance'` | Centers and decorrelates data via PCA whitening before unmixing (`false` assumes input is already whitened and skips centering). |
| `fun` | `'logcosh' \| 'exp' \| 'cube'` | `'logcosh'` | Negentropy contrast nonlinearity (`'logcosh'` is robust general-purpose; `'exp'` works well for super-Gaussian signals). |
| `funArgs` | `{ alpha?: number }` | `{ alpha: 1.0 }` | Parameter `alpha` in `[1, 2]` for `'logcosh'`. |
| `maxIter` / `tol` | `number` | `200` / `1e-4` | Fixed-point convergence budget and tolerance. |
| `randomState` | `number` | `undefined` | Seed for initial unmixing matrix. |

### Methods & properties

- `fit(X)` / `transform(X)` / `fitTransform(X)` / `inverseTransform(S)` — unmix signals and reconstruct observations.
- Learned fields: `components` (unmixing matrix), `mixing` (pseudo-inverse mixing matrix), `mean`, and `nIter`.
