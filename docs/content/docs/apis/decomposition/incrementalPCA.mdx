## Algorithm overview

Standard [PCA](/docs/apis/decomposition/pca) loads the entire centered feature matrix into memory at once to compute its singular value decomposition. When processing large CSV uploads in a browser tab, streaming telemetry chunks in Node.js, or running inside memory-capped serverless functions, holding every row simultaneously can exhaust heap limits.

**Incremental PCA** updates a mean-corrected low-rank SVD **one mini-batch at a time** via `partialFit()`, maintaining constant memory proportional to `batchSize × nFeatures` rather than total dataset size. Once all batches have been seen, it supports the exact same `transform()` and `inverseTransform()` projections as batch PCA.

## JavaScript implementation

`Decomposition.IncrementalPCA` in `@kanaries/ml` implements Ross et al.'s mean-corrected incremental SVD update (matching `sklearn.decomposition.IncrementalPCA`) in pure TypeScript. You can stream arbitrary chunks manually with chained `partialFit(batch)` calls, or pass a full matrix to `fit(X)` and let `batchSize` chunk it automatically. Fitted models serialize via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Decomposition } from '@kanaries/ml';

const batchOne = [[0, 1, 2], [1, 2, 3], [2, 1, 4]];
const batchTwo = [[3, 4, 2], [4, 3, 1], [5, 5, 0]];
const nextBatch = [[2, 3, 2]];

const pca = new Decomposition.IncrementalPCA({ nComponents: 2 });
pca.partialFit(batchOne).partialFit(batchTwo);
const embedding = pca.transform(nextBatch);
console.log({ embedding, seen: pca.nSamplesSeen });
```

## Detailed API reference

### `new Decomposition.IncrementalPCA(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nComponents` | `number \| null` | `null` (`min(batchSize, nFeatures)`) | Number of principal components retained across batches. |
| `batchSize` | `number` | `5 * nFeatures` | Chunk size used when calling `fit(X)` on an in-memory matrix. |

### Methods & properties

| Member | Signature | Description |
| --- | --- | --- |
| `partialFit` | `(X: number[][]) => this` | Updates the running mean, sample count, and low-rank SVD with a new batch (chainable). |
| `fit` | `(X: number[][]) => void` | Resets state and streams `X` in `batchSize` chunks through `partialFit()`. |
| `transform` / `inverseTransform` | `(X: number[][]) => number[][]` | Projects samples onto principal axes or reconstructs them in feature space. |
| `components` / `mean` / `explainedVariance` / `singularValues` / `nSamplesSeen` | Learned getters | Inspects principal directions, running column means, variance spectrum, and total rows processed. |

### Practical constraints

- **Minimum first batch size**: The very first `partialFit()` call must contain at least `nComponents` rows (and `nFeatures >= nComponents`), otherwise there are not enough samples to initialize the requested rank.
