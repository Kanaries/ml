## Algorithm overview

**Latent Dirichlet Allocation (LDA)** is a generative probabilistic topic model that discovers hidden semantic themes across a collection of text documents. It assumes every document is a soft probability mixture over `nComponents` latent topics, and every topic is a probability distribution over vocabulary terms.

Unlike [NMF](/docs/apis/decomposition/nmf) (which operates cleanly on TF-IDF weights via matrix factorization), LDA is designed specifically for **raw non-negative word-count matrices** produced by [`CountVectorizer`](/docs/apis/feature_extraction/countVectorizer). Each row returned by `transform()` is a normalized topic-proportion vector summing to `1`, making it easy to cluster articles, tag support logs, or chart theme distributions directly in a frontend dashboard.

*(Note: For supervised classification/projection Linear Discriminant Analysis, see [`DiscriminantAnalysis.LDA`](/docs/apis/discriminant-analysis/lda).)*

## JavaScript implementation

`Decomposition.LatentDirichletAllocation` runs batch variational Bayes inference in pure TypeScript for browser and Node.js environments. It accepts both dense `number[][]` and sparse [`CSRMatrix`](/docs/apis/data) count matrices, chains directly after `FeatureExtraction.CountVectorizer` inside a [`Pipeline`](/docs/apis/pipeline), and serializes trained topic models via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start

```ts
import { Decomposition, FeatureExtraction } from '@kanaries/ml';

const documents = ['cats chase mice', 'dogs chase balls', 'cats and dogs', 'mice eat cheese'];
const counts = new FeatureExtraction.CountVectorizer().fitTransform(documents);
const lda = new Decomposition.LatentDirichletAllocation({
  nComponents: 2,
  maxIter: 15,
  randomState: 0,
});
const topics = lda.fitTransform(counts);
console.log({ topics, nTopics: lda.components.length });
```

## Detailed API reference

### `new Decomposition.LatentDirichletAllocation(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nComponents` | `number` | `10` | Number of latent topics to infer. |
| `docTopicPrior` | `number` | `1 / nComponents` | Dirichlet prior `alpha` controlling document-topic sparsity (smaller values encourage fewer topics per document). |
| `topicWordPrior` | `number` | `1 / nComponents` | Dirichlet prior `eta` controlling topic-word sparsity (smaller values produce sharper top-word lists). |
| `maxIter` | `number` | `10` | Number of variational EM passes over the corpus. |
| `maxDocUpdateIter` | `number` | `100` | Inner E-step iterations per document. |
| `meanChangeTol` | `number` | `1e-3` | Convergence threshold for per-document variational updates. |
| `randomState` | `number` | `undefined` | Seed for reproducible topic initialization. |

### Methods & properties

- `fit(X)` / `transform(X)` / `fitTransform(X)` — accept dense or `CSRMatrix` non-negative counts; `transform` returns normalized document-topic distributions.
- `components` — unnormalized topic-word variational parameters (`[nComponents][nVocab]`); sort each row descending to inspect top keywords per topic.
