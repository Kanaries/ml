## Algorithm overview

**NearestCentroid** (also known as the **Rocchio classifier** in information retrieval) summarizes each training class by a single prototype vector—the **centroid** (mean) of its samples—and assigns every test observation to the class whose centroid lies closest under the chosen distance metric.

Because prediction only computes distances against `K` class centroids instead of all `N` training samples, `NearestCentroid` offers `O(K * d)` inference time and tiny memory footprints—orders of magnitude faster than full [k-Nearest Neighbors](/docs/apis/neighbors/knn) when `N` is large and classes form well-separated convex groups.

## JavaScript implementation

`@kanaries/ml` provides `Neighbors.NearestCentroid` in pure TypeScript for browser and Node.js applications. It supports all distance metrics in `Metrics.Distance` (including `'euclidean'`, `'manhattan'`, `'cosine'`, and Minkowski `p`), composes inside [`Pipeline`](/docs/apis/pipeline), and serializes into compact JSON payloads via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Neighbors } from '@kanaries/ml';

const clf = new Neighbors.NearestCentroid({ metric: 'euclidean' });
clf.fit([[0, 0], [0, 1], [4, 4], [5, 4]], [0, 0, 1, 1]);
const pred = clf.predict([[1, 1], [4, 5]]);
console.log(pred);
```

## Detailed API reference

### `new Neighbors.NearestCentroid(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `metric` | `Distance.IDistanceType` | `'euclidean'` | Distance function measuring proximity to each class centroid (`'cosine'` works well for normalized TF-IDF or embedding vectors). |
| `p` | `number` | `2` | Minkowski power parameter when `metric: 'minkowski'`. |

### Methods & limitations

- `fit(trainX: number[][], trainY: number[]): void` — computes one centroid vector per unique numeric class label.
- `predict(testX: number[][]): number[]` — returns the label of the nearest centroid (ties resolve to the numerically smaller class label).
- **When to upgrade**: Because `NearestCentroid` assumes spherical, equal-variance classes, it struggles when classes differ in variance or have non-convex shapes. Compare against [`DiscriminantAnalysis.LDA`](/docs/apis/discriminant-analysis/lda), [`DiscriminantAnalysis.QDA`](/docs/apis/discriminant-analysis/qda), or [`Neighbors.KNearestNeighbors`](/docs/apis/neighbors/knn).
