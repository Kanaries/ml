## Algorithm overview

**Local Outlier Factor (LOF)** is an unsupervised anomaly-detection algorithm that compares each sample's **local reachability density** against the densities of its `nNeighbors` nearest neighbors. Points residing in a region substantially sparser than their immediate neighborhood receive a high LOF ratio (strongly negative `negativeOutlierFactor`) and are flagged as outliers (`-1`).

LOF solves a classic failure mode of global anomaly detectors: when a dataset contains **multiple clusters of different densities** (for example, one tightly packed urban cluster and one broad rural cluster), global distance thresholds either miss anomalies hovering near the dense cluster or falsely flag normal points inside the sparse cluster. Because LOF normalizes every point relative to its *local* neighborhood, it catches both cleanly.

## JavaScript implementation

`Neighbors.LocalOutlierFactor` runs in pure TypeScript across browsers and Node.js and mirrors scikit-learn's two explicit operating modes:

- **Outlier detection (`novelty: false`, default)**: call `fitPredict(X)` to flag anomalies inside the training batch itself (`1` = inlier, `-1` = outlier).
- **Novelty detection (`novelty: true`)**: call `fit(XClean)` on normal data, then call `predict(XNew)`, `decisionFunction(XNew)`, or `scoreSamples(XNew)` on unseen production rows—and serialize the fitted detector with `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Neighbors } from '@kanaries/ml';

const X = [[0, 0], [0.1, 0.2], [0.2, 0.1], [1, 1], [8, 8]];
const labels = new Neighbors.LocalOutlierFactor({
  nNeighbors: 2,
  contamination: 0.2,
}).fitPredict(X);

const novelty = new Neighbors.LocalOutlierFactor({ nNeighbors: 2, novelty: true });
novelty.fit(X);
console.log({ labels, noveltyPreds: novelty.predict([[0.15, 0.1], [20, 20]]) });
```

## Detailed API reference

### `new Neighbors.LocalOutlierFactor(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nNeighbors` | `number` | `20` | Neighborhood size used to estimate local density (must be smaller than `X.length`). |
| `contamination` | `number \| 'auto'` | `'auto'` | Expected outlier fraction in `(0, 0.5]`, or `'auto'` (uses offset `-1.5` matching scikit-learn). |
| `novelty` | `boolean` | `false` | `false` enables `fitPredict(X)` only; `true` enables `fit(X)` + `predict` / `decisionFunction` / `scoreSamples` on new rows. |

### Methods & properties

- `fitPredict(X)` (`novelty: false`) — returns `1` (inlier) and `-1` (outlier); read `negativeOutlierFactor` (values near `-1` are normal; values much smaller than `-1` are outliers).
- `fit(X)` / `scoreSamples(X)` / `decisionFunction(X)` / `predict(X)` (`novelty: true`) — scores unseen observations against `offset`.
