## Algorithm overview

**Unsupervised Nearest Neighbors (`NearestNeighbors`)** indexes a reference dataset without target labels and answers two foundational spatial queries:

- **`kneighbors(X, nNeighbors)`**: returns the `k` closest points and their sorted distances for every query vector (or each training point's nearest *other* neighbors when `X` is omitted).
- **`radiusNeighbors(X, radius)`**: returns every reference sample lying within a fixed distance cutoff `radius`.

It powers similarity search, client-side embedding lookup, near-duplicate detection, DBSCAN `eps` knee-plot estimation, and graph construction for manifold learning.

## JavaScript implementation

`Neighbors.NearestNeighbors` in `@kanaries/ml` provides scikit-learn's `fit`, `kneighbors`, and `radiusNeighbors` API in pure TypeScript for browser and Node.js environments. You can pick `'brute'`, `'kdTree'`, `'ballTree'`, or `'auto'` indexing; when serialized with `toJSON()` / [`loadModel()`](/docs/apis/serialization), only the reference matrix and parameters are stored and spatial trees rebuild safely on load.

## Quick start

```ts
import { Neighbors } from '@kanaries/ml';

const search = new Neighbors.NearestNeighbors({
  nNeighbors: 2,
  algorithm: 'kdTree',
});
search.fit([[0], [2], [5]]);

console.log(search.kneighbors([[1]]));
// { distances: [[1, 1]], indices: [[0, 1]] }
```

## Detailed API reference

### `new Neighbors.NearestNeighbors(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nNeighbors` | `number` | `5` | Default number of neighbors returned by `kneighbors()`. |
| `radius` | `number` | `1.0` | Default distance threshold used by `radiusNeighbors()`. |
| `algorithm` | `'auto' \| 'brute' \| 'kdTree' \| 'ballTree'` | `'auto'` | Spatial search backend (`kdTree` shines in low dimensions `d ≤ 15`; `ballTree` handles general metrics; `brute` is fastest in high dimensions or small `n`). |
| `leafSize` | `number` | `30` | Leaf bucket size for `kdTree` and `ballTree`. |
| `metric` / `p` | `Distance.IDistanceType` / `number` | `'euclidean'` / `2` | Distance metric and Minkowski order. |

### Methods

- `fit(X: number[][]): void` — stores the reference dataset and prepares the chosen spatial structure.
- `kneighbors(X?, nNeighbors?, returnDistance?)` — returns `{ distances, indices }` (or `indices` alone when `returnDistance: false`). Omitting `X` queries each training sample against all *other* training points.
- `radiusNeighbors(X?, radius?, returnDistance?)` — returns neighbors within `radius` for each query point.
