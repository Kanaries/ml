## Algorithm overview

**RadiusNeighborsClassifier** is a non-parametric classifier that predicts a query point's class by voting across **every training observation within a fixed distance `radius`**, rather than always pulling a fixed count `k` of neighbors.

This distinction matters in unevenly sampled feature spaces:

- In **dense regions**, radius search automatically averages over more nearby evidence for lower variance.
- In **sparse or out-of-distribution regions**, standard k-NN forces votes from distant, unrelated points—whereas `RadiusNeighborsClassifier` recognizes that no neighbors lie within `radius` and explicitly returns your configured `outlierLabel` (or throws an error so your app can flag an unknown input).

## JavaScript implementation

`@kanaries/ml` provides `Neighbors.RadiusNeighborsClassifier` in pure TypeScript for browser and Node.js apps with `'uniform'` or `'distance'` voting, configurable `Metrics.Distance` metrics, explicit `outlierLabel` handling, [`Pipeline`](/docs/apis/pipeline) support, and JSON persistence via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Neighbors } from '@kanaries/ml';

const clf = new Neighbors.RadiusNeighborsClassifier({
  radius: 1.5,
  weights: 'uniform',
  outlierLabel: -1,
});

clf.fit([[0], [1], [4]], [0, 0, 1]);
const pred = clf.predict([[0.5], [10]]);
console.log(pred); // [0, -1]
```

## Detailed API reference

### `new Neighbors.RadiusNeighborsClassifier(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `radius` | `number` | `1.0` | Maximum distance defining the local voting neighborhood. |
| `weights` | `'uniform' \| 'distance'` | `'uniform'` | Equal vote per neighbor or inverse-distance weighting. |
| `metric` / `p` | `Distance.IDistanceType` / `number` | `'euclidean'` / `2` | Distance metric and Minkowski order. |
| `outlierLabel` | `number \| null` | `null` | Fallback class returned when zero neighbors fall within `radius`. If `null`, `predict()` throws an error on isolated points. |

### Methods & tuning tips

- `fit(trainX, trainY)` / `predict(testX)` — always standardize numeric features with [`StandardScaler`](/docs/apis/utils/preprocessing) first so `radius` has consistent scale across dimensions.
