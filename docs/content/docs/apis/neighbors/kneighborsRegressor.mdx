## Algorithm overview

**KNeighborsRegressor (k-NN Regression)** is a non-parametric, instance-based regressor that predicts a query sample's continuous target by averaging the `y` values of its `nNeighbors` closest training observations. Rather than fitting a global algebraic equation, it adapts locally to arbitrary curves, step changes, and multi-modal surfaces.

Choosing between uniform and distance weighting controls local smoothness:

- **`weights: 'uniform'`**: every neighbor contributes equally (`1 / k`), smoothing out local measurement noise.
- **`weights: 'distance'`**: closer neighbors receive higher inverse-distance weight (`1 / d`), reducing bias near sharp transitions and reproducing exact training points.

## JavaScript implementation

`@kanaries/ml` provides `Neighbors.KNeighborsRegressor` in pure TypeScript for browser and Node.js runtimes. Prefer the options-object constructor (`{ nNeighbors, weights, metric, p }`) over the deprecated positional form. It supports all distance metrics in `Metrics.Distance`, plugs into [`Pipeline`](/docs/apis/pipeline), and serializes cleanly via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Neighbors } from '@kanaries/ml';

const reg = new Neighbors.KNeighborsRegressor({ nNeighbors: 2, weights: 'distance' });
reg.fit([[0], [1], [3]], [0, 1, 3]);
const pred = reg.predict([[2]]);
console.log(pred);
```

## Detailed API reference

### `new Neighbors.KNeighborsRegressor(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nNeighbors` | `number` | `5` | Number of nearest neighbors averaged per prediction. Smaller values fit finer detail; larger values smooth noise. |
| `weights` | `'uniform' \| 'distance'` | `'uniform'` | Neighbor weighting scheme. |
| `metric` | `Distance.IDistanceType` | `'euclidean'` | Distance metric (`'euclidean'`, `'manhattan'`, `'minkowski'`, `'cosine'`, etc.). |
| `p` | `number` | `2` | Order parameter when `metric: 'minkowski'` (`1` = Manhattan, `2` = Euclidean). |

### Methods & practical guidance

- `fit(trainX: number[][], trainY: number[]): void` — stores the reference training set.
- `predict(testX: number[][]): number[]` — computes weighted neighbor averages for each query row.
- **Feature scaling is mandatory**: Wrap `StandardScaler` and `KNeighborsRegressor` inside a [`Pipeline`](/docs/apis/pipeline) so large-magnitude columns do not dominate distance calculations.
- **Related pages**: [K-Nearest Neighbors Classifier](/docs/apis/neighbors/knn), [RadiusNeighborsRegressor](/docs/apis/neighbors/radiusNeighborsRegressor), [KNN Playground](/playground/knn).
