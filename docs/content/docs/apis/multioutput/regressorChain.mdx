## Algorithm overview

**RegressorChain** predicts multiple continuous targets (`Y` of shape `[nSamples][nTargets]`) simultaneously while modeling dependencies across outputs. Targets are arranged in a sequence (`order`): the first regressor predicts target `order[0]` from `X`, the second regressor predicts `order[1]` from `[X, target_0]`, and each subsequent regressor augments `X` with all preceding targets in the chain.

This design is especially valuable when outputs obey physical, financial, or temporal coupling—for example predicting both item demand and fulfillment cost, or multi-step horizon values where earlier predictions strongly inform later ones.

## JavaScript implementation

`MultiOutput.RegressorChain` wraps any registered single-output `@kanaries/ml` regressor in pure TypeScript for browser and Node.js runtimes. Prefer regularized base learners like [`Linear.RidgeRegression`](/docs/apis/linear/ridgeRegression) when correlated target columns could introduce collinearity into augmented matrices. Setting `cv` uses out-of-fold predictions during training so downstream models adapt to realistic upstream prediction error. Fitted chains serialize via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Linear, MultiOutput } from '@kanaries/ml';

const X = [[0], [1], [2], [3]];
const targets = [[0, 1], [1, 3], [2, 5], [3, 7]];
const testX = [[4]];
const chain = new MultiOutput.RegressorChain({
  estimator: new Linear.RidgeRegression({ alpha: 1 }),
  order: [1, 0],
});
chain.fit(X, targets);
const predictions = chain.predict(testX);
console.log(predictions);
```

## Detailed API reference

### `new MultiOutput.RegressorChain(props)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `estimator` | `RegressorBase` | *required* | Prototype single-output regressor cloned for each target in the chain. |
| `order` | `number[] \| 'random'` | `[0, 1, ..., T-1]` | Order in which targets are predicted and appended as features. |
| `cv` | `number \| null` | `null` | Integer fold count (`≥ 2`) for out-of-fold upstream training predictions. |
| `randomState` | `number` | `undefined` | Seed for `'random'` chain order. |

### Methods & properties

- `fit(X, Y)` / `predict(X)` / `score(X, Y)` (mean R² across all outputs).
- `chainOrder` and `estimators` expose defensive copies of the resolved order and fitted regressors.
