## Algorithm overview

**ClassifierChain** solves multi-label binary classification (`Y` of shape `[nSamples][nLabels]`) while capturing correlations among output labels. Instead of fitting `L` completely isolated binary classifiers, it arranges the `L` labels in a sequence (`order`):

1. Classifier `0` predicts the first label from the original feature matrix `X`.
2. Classifier `1` receives `[X, label_0]` as input to predict the second label.
3. Classifier `k` receives `[X, label_0, ..., label_{k-1}]`, allowing co-occurrence and mutual-exclusion patterns across labels to directly inform later predictions.

During inference (`predict` / `predictProba`), each link feeds its predicted output forward down the chain. Setting `cv` (for example `cv: 3`) uses out-of-fold predictions rather than ground-truth labels during training, aligning training-time and test-time distributions.

## JavaScript implementation

`MultiOutput.ClassifierChain` accepts any registered single-output `@kanaries/ml` classifier (such as `Bayes.GaussianNB`, `Linear.LogisticRegression`, or `Tree.DecisionTreeClassifier`), runs synchronously in browsers and Node.js, supports explicit or `'random'` seeded ordering, and serializes via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Bayes, MultiOutput } from '@kanaries/ml';

const X = [[0], [1], [2]];
const testX = [[1.5]];
const chain = new MultiOutput.ClassifierChain({
  estimator: new Bayes.GaussianNB(),
  order: [0, 1],
});
chain.fit(X, [[0, 0], [0, 1], [1, 1]]);
const labels = chain.predict(testX);
console.log(labels);
```

## Detailed API reference

### `new MultiOutput.ClassifierChain(props)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `estimator` | `ClassifierBase` | *required* | Prototype binary classifier cloned once per label in the chain. |
| `order` | `number[] \| 'random'` | `[0, 1, ..., L-1]` | Explicit permutation of label indices or `'random'` for a shuffled chain order. |
| `cv` | `number \| null` | `null` | When set (`≥ 2`), generates out-of-fold predictions for upstream chain columns during `fit()` to reduce exposure bias. |
| `randomState` | `number` | `undefined` | Seed for `'random'` order and CV splits. |

### Methods & properties

- `fit(X, Y)` / `predict(X)` / `predictProba(X)` (requires base estimator to implement `predictProba`) / `score(X, Y)` (exact-match subset accuracy).
- `chainOrder` and `estimators` return defensive copies of the resolved order and fitted members.
