## Algorithm overview

**CountVectorizer** converts a collection of raw text strings into a sparse document-term matrix of token and n-gram occurrence counts. It handles lowercasing, stop-word filtering, configurable n-gram windows (`ngramRange`), document-frequency pruning (`minDf`, `maxDf`), and vocabulary capping (`maxFeatures`).

Bag-of-words count matrices are the required input for probabilistic count models such as [`Decomposition.LatentDirichletAllocation`](/docs/apis/decomposition/latentDirichletAllocation) and [`Bayes.MultinomialNB`](/docs/apis/bayes/multinomialNB), and serve as the foundation for [`TfidfTransformer`](/docs/apis/feature_extraction/tfidfTransformer).

## JavaScript implementation

`FeatureExtraction.CountVectorizer` runs in pure TypeScript across browsers and Node.js and returns a [`CSRMatrix`](/docs/apis/data) so large vocabularies never blow up heap memory. Fitted vocabularies serialize cleanly with `toJSON()` / [`loadModel()`](/docs/apis/serialization) and compose inside [`Pipeline`](/docs/apis/pipeline).

## Quick start example

```ts
import { FeatureExtraction } from '@kanaries/ml';

const vectorizer = new FeatureExtraction.CountVectorizer({
  ngramRange: [1, 2],
  minDf: 1,
  stopWords: ['the'],
});
const counts = vectorizer.fitTransform(['the red fox', 'the red bird']);
console.log(vectorizer.getFeatureNamesOut(), counts.toDense());
```

## Detailed API reference

### `new FeatureExtraction.CountVectorizer(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `lowercase` | `boolean` | `true` | Lowercase input strings before tokenization. |
| `stopWords` | `string[]` | `[]` | Exact tokens excluded from the learned vocabulary. |
| `ngramRange` | `[number, number]` | `[1, 1]` | Inclusive `[minN, maxN]` token n-gram range (for example `[1, 2]` for unigrams + bigrams). |
| `minDf` / `maxDf` | `number` | `1` / `1` | Document-frequency bounds. Values `< 1` (`<= 1` for `maxDf`) act as proportions of total documents; integers `> 1` act as absolute document counts. |
| `maxFeatures` | `number` | `undefined` | Retain only the top `maxFeatures` terms ordered by corpus frequency. |
| `binary` | `boolean` | `false` | Store `1` for presence instead of raw counts (ideal for [`Bayes.BernoulliNB`](/docs/apis/bayes/bernoulliNB)). |
| `vocabulary` | `Record<string, number> \| Map<string, number>` | `undefined` | Fixed pre-supplied term-to-index map bypassing vocabulary learning. |

### Methods & properties

- `fit(documents)` / `transform(documents)` / `fitTransform(documents)` — produce sparse `CSRMatrix` outputs.
- `getFeatureNamesOut()` and `vocabulary` expose learned column names and a defensive `ReadonlyMap`.
