## Algorithm overview

**TfidfTransformer** converts an existing non-negative term-count matrix (dense `number[][]` or sparse [`CSRMatrix`](/docs/apis/data)) into a TF-IDF weighted sparse matrix. Scaling raw counts by inverse document frequency suppresses ubiquitous filler words while highlighting terms specific to individual documents, and L2 row normalization ensures long documents do not overwhelm short documents under dot-product or cosine similarity.

Use `TfidfTransformer` separately from [`TfidfVectorizer`](/docs/apis/feature_extraction/tfidfVectorizer) when counts already come from a custom tokenizer, [`CountVectorizer`](/docs/apis/feature_extraction/countVectorizer), [`HashingVectorizer`](/docs/apis/feature_extraction/hashingAndDictionaries), or an upstream analytics SQL table.

## JavaScript implementation

`FeatureExtraction.TfidfTransformer` runs in pure TypeScript across browsers and Node.js. It accepts both dense and sparse `CSRMatrix` inputs, always returns a memory-efficient `CSRMatrix`, plugs into [`Pipeline`](/docs/apis/pipeline), and persists learned `idf` weights via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { FeatureExtraction } from '@kanaries/ml';

const tfidf = new FeatureExtraction.TfidfTransformer({ norm: 'l2' });
const weighted = tfidf.fitTransform([[2, 0, 1], [0, 1, 1]]);
console.log({ idf: tfidf.idf, dense: weighted.toDense() });
```

## Detailed API reference

### `new FeatureExtraction.TfidfTransformer(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `norm` | `'l1' \| 'l2' \| null` | `'l2'` | Row-wise normalization applied after weighting (`'l2'` makes dot products equal cosine similarity). |
| `useIdf` | `boolean` | `true` | Multiply term frequencies by learned inverse document frequencies (`false` applies normalization only). |
| `smoothIdf` | `boolean` | `true` | Adds `1` to document frequencies (`log((1 + n) / (1 + df)) + 1`), preventing division by zero on unseen terms. |
| `sublinearTf` | `boolean` | `false` | Replaces raw term frequency `tf` with `1 + log(tf)` for non-zero counts. |

### Methods & properties

- `fit(X)` / `transform(X)` / `fitTransform(X)` — require non-negative numeric counts matching the fitted column count; return `CSRMatrix`.
- `idf: number[]` — returns a defensive copy of learned IDF weights.
