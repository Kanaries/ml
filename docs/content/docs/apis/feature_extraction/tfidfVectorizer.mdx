## Algorithm overview

**TfidfVectorizer** combines tokenization, vocabulary learning, term-frequency counting, inverse-document-frequency (IDF) weighting, and row normalization into a single transformer. Words that appear in nearly every document ("the", "system", "update") are down-weighted automatically, while rare discriminative terms receive higher weight—making TF-IDF the standard workhorse for lightweight text classification, document clustering, keyword extraction, and client-side semantic search baselines.

Because TF-IDF vectors are mostly zeros, returning a sparse [`CSRMatrix`](/docs/apis/data) avoids allocating huge dense arrays in browser tabs and Node.js services.

## JavaScript implementation

`FeatureExtraction.TfidfVectorizer` runs in pure TypeScript across browsers and Node.js. It accepts `string[]`, returns a `CSRMatrix`, plugs directly into [`Pipeline`](/docs/apis/pipeline) ahead of sparse-aware estimators (`MultinomialNB`, `ComplementNB`), and serializes its learned vocabulary and `idf` vector via `JSON.stringify()` and [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Bayes, FeatureExtraction, Pipeline } from '@kanaries/ml';

const pipeline = new Pipeline({
  steps: [
    ['tfidf', new FeatureExtraction.TfidfVectorizer({ ngramRange: [1, 2] })],
    ['nb', new Bayes.MultinomialNB()],
  ],
});
pipeline.fit(['red apple sweet', 'blue sea deep'], [0, 1]);
console.log(pipeline.predict(['deep blue ocean']));
```

## Detailed API reference

### `new FeatureExtraction.TfidfVectorizer(props?)`

Accepts every [`CountVectorizer`](/docs/apis/feature_extraction/countVectorizer) option (`lowercase`, `stopWords`, `ngramRange`, `minDf`, `maxDf`, `maxFeatures`, `binary`, `vocabulary`) plus every [`TfidfTransformer`](/docs/apis/feature_extraction/tfidfTransformer) option (`norm`, `useIdf`, `smoothIdf`, `sublinearTf`).

### Methods & properties

| Member | Signature | Description |
| --- | --- | --- |
| `fit` | `(documents: string[]) => void` | Learns vocabulary and inverse-document-frequency weights. |
| `transform` / `fitTransform` | `(documents: string[]) => CSRMatrix` | Transforms raw text into a sparse TF-IDF `CSRMatrix`. |
| `getFeatureNamesOut` | `() => string[]` | Returns vocabulary terms in column index order. |
| `vocabulary` / `idf` | `ReadonlyMap<string, number>` / `number[]` | Defensive copies of the term-to-column map and IDF weights. |

### Tuning tips

- Set `maxFeatures` (for example `5000`) and `minDf: 2` on large browser corpora to cap vocabulary width and keep serialized `toJSON()` payloads compact.
- Enable `sublinearTf: true` (`1 + log(tf)`) when long documents repeat keywords heavily compared to short documents.
