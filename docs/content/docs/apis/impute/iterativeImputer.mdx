## Algorithm overview

**IterativeImputer** (Multivariate Imputation by Chained Equations / MICE) models each column containing missing `NaN` values as a regression target predicted from all remaining feature columns. Starting from a simple univariate fill (`initialStrategy`: `'mean'`, `'median'`, `'mostFrequent'`, or `'constant'`), it cycles through incomplete features in rounds—refitting a regressor per column and updating imputed entries—until changes fall below `tol` or `maxIter` rounds complete.

Because it exploits cross-column correlations, `IterativeImputer` preserves covariance structure far better than single-column mean/median filling—especially before linear models, [PCA](/docs/apis/decomposition/pca), or clustering.

## JavaScript implementation

`Impute.IterativeImputer` runs in pure TypeScript across browsers and Node.js. It defaults to lightly regularized `RidgeRegression` and accepts any registered `@kanaries/ml` regressor via `estimator` (such as [`Linear.BayesianRidge`](/docs/apis/linear/bayesianRegressors) or [`Ensemble.ExtraTreesRegressor`](/docs/apis/ensemble/extraTreesRegressor) for non-linear relationships). It records its fitted `imputationSequence` so `transform(XTest)` replays the exact learned predictors without peeking at test labels, and serializes via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Impute } from '@kanaries/ml';

const imputer = new Impute.IterativeImputer({ maxIter: 10, tol: 1e-3 });
const complete = imputer.fitTransform([[0, 1], [1, 3], [2, NaN], [3, 7]]);
const future = imputer.transform([[4, NaN]]);
console.log({ complete, future });
```

## Detailed API reference

### `new Impute.IterativeImputer(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `estimator` | `RegressorBase` | `RidgeRegression` | Registered regressor cloned and fitted per feature round (e.g. `Linear.BayesianRidge`). |
| `maxIter` / `tol` | `number` | `10` / `1e-3` | Maximum round-robin passes and convergence threshold. |
| `initialStrategy` | `'mean' \| 'median' \| 'mostFrequent' \| 'constant'` | `'mean'` | Initial fill before iterative refinement (`fillValue` sets the value for `'constant'`). |
| `imputationOrder` | `'ascending' \| 'descending' \| 'roman' \| 'arabic' \| 'random'` | `'ascending'` | Column traversal order per round. |
| `skipComplete` | `boolean` | `false` | Skip fitting regressors for columns with zero missing values during `fit()`. |
| `minValue` / `maxValue` | `number \| number[]` | `-Infinity` / `Infinity` | Optional domain bounds clamping imputed outputs. |
| `randomState` | `number` | `undefined` | Seed used when `imputationOrder: 'random'`. |

### Methods & properties

- `fit(X)` / `fitTransform(X)` / `transform(X)` — represent missing entries with `NaN`.
- `imputationSequence` and `nIter` expose the fitted column estimators and convergence rounds.
