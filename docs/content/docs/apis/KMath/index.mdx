## Module overview

Exploratory data analysis, browser CSV profilers, z-score outlier rules, and feature engineering pipelines constantly need crisp descriptive statistics—mean, sample vs. population variance, standard deviation, and pairwise covariance—with clear degrees-of-freedom semantics (`ddof = 0` vs `ddof = 1`).

The **`KMath`** module packages `@kanaries/ml`'s lightweight, zero-dependency numeric statistics helpers for flat `number[]` vectors so you can profile columns and compute summary metrics without adding another math dependency.

## JavaScript implementation

Import helpers from `import { KMath } from '@kanaries/ml'` in browser and Node.js codebases. Every function operates on standard JavaScript `number[]` arrays and explicitly distinguishes **sample** (`n - 1` denominator: `varSample`, `SDSample`) from **population** (`n` denominator: `varPopulation`, `SDPopulation`) estimators so results match NumPy (`ddof=1` vs `ddof=0`) cleanly.

## Quick start example

```ts
import { KMath } from '@kanaries/ml';

const values = [1, 2, 3, 4];
const mean = KMath.expected(values);
const sampleVariance = KMath.varSample(values);
const populationSd = KMath.SDPopulation(values);
const cov = KMath.covariance([1, 2, 3, 4], [2, 4, 5, 8]);
console.log({ mean, sampleVariance, populationSd, cov });
```

## Detailed API reference

| Function | Signature | Description |
| --- | --- | --- |
| `KMath.sum` | `(nums: number[]) => number` | Arithmetic sum of all elements. |
| `KMath.expected` | `(nums: number[]) => number` | Arithmetic mean (`sum(nums) / nums.length`). |
| `KMath.variance` | `(nums: number[], df: number) => number` | Variance with explicit denominator `nums.length - df`. |
| `KMath.varSample` / `KMath.SDSample` | `(nums: number[]) => number` | Unbiased sample variance and standard deviation (`n - 1`). |
| `KMath.varPopulation` / `KMath.SDPopulation` | `(nums: number[]) => number` | Population variance and standard deviation (`n`). |
| `KMath.covariance` | `(X: number[], Y: number[]) => number` | Pairwise covariance between equal-length numeric arrays `X` and `Y`. |
