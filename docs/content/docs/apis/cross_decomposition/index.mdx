## Algorithm overview

When a dataset has many strongly collinear predictors (`X`)—or even more columns than samples—and multiple correlated targets (`Y`), ordinary least squares becomes ill-conditioned while unsupervised [PCA](/docs/apis/decomposition/pca) can discard low-variance directions that actually predict `Y`. **Cross Decomposition** finds paired latent projections of both `X` and `Y` simultaneously:

- **`PLSRegression` (Partial Least Squares)**: extracts latent components maximizing **covariance** between `X` scores and `Y` scores via mode-A NIPALS with regression deflation—a staple in chemometrics, spectroscopy, and wide multi-output tabular forecasting.
- **`CCA` (Canonical Correlation Analysis)**: extracts latent projections maximizing **correlation** between `X` and `Y` via mode-B weights with canonical deflation—ideal for multi-view alignment (comparing two paired sensor arrays or behavioral feature blocks).

## JavaScript implementation

`CrossDecomposition.PLSRegression` and `CrossDecomposition.CCA` run in pure TypeScript across browsers and Node.js, support both `transform()` (latent score extraction) and `predict()` (multi-target prediction), compose inside [`Pipeline`](/docs/apis/pipeline), and serialize via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start

```ts
import { CrossDecomposition } from '@kanaries/ml';

const X = [[0, 1], [1, 2], [2, 3], [3, 5]];
const Y = [[1], [2], [4], [7]];
const model = new CrossDecomposition.PLSRegression({ nComponents: 2 });
model.fit(X, Y);
console.log(model.predict([[4, 6]]));
```

## Detailed API reference

| Option | Default | Description |
| --- | --- | --- |
| `nComponents` | `2` | Number of latent cross-decomposition components (at most `min(nSamples, nFeaturesX, nFeaturesY)`). |
| `scale` | `true` | Standardize `X` and `Y` internally before NIPALS iterations. |
| `maxIter` / `tol` | `500` / `1e-6` | NIPALS iteration cap and convergence tolerance. |

Both estimators expose `fit(X, Y)`, `transform(X, Y?)`, `predict(X)`, plus fitted `xWeights`, `yWeights`, `xLoadings`, `yLoadings`, `xRotations`, `yRotations`, `coef`, and `nIter`.
