## Algorithm overview

**ExtraTreesClassifier** (Extremely Randomized Trees) builds an ensemble of randomized decision trees similar to [RandomForestClassifier](/docs/apis/ensemble/randomForestClassifier), but goes one step further in randomization: instead of searching for the exact optimal split threshold on every candidate feature, each node draws **random split thresholds** for each candidate feature and keeps the best among those random cuts.

This extra randomness brings two practical advantages:

- **Lower variance on noisy features**: randomized thresholds prevent trees from clinging to minor fluctuations in continuous measurements.
- **Faster tree construction**: evaluating a few random thresholds instead of scanning every sorted unique value speeds up training in JavaScript, especially on continuous tabular datasets.

## JavaScript implementation

`Ensemble.ExtraTreesClassifier` trains independent [`ExtraTreeClassifier`](/docs/apis/tree/extraTreeClassifier) members in pure TypeScript, averages their leaf class probabilities (`predictProba`), and selects the highest-probability class in `predict`. It exposes normalized `featureImportances` and sorted `classes` after fitting, supports deterministic `randomState` seeds, and serializes via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Ensemble } from '@kanaries/ml';

const model = new Ensemble.ExtraTreesClassifier({
  nEstimators: 100,
  max_features: 'sqrt',
  randomState: 42,
});
model.fit([[0, 0], [0, 1], [3, 3], [4, 3]], [0, 0, 1, 1]);
console.log(model.predict([[0.2, 0.1], [3.5, 3]]), model.featureImportances);
```

## Detailed API reference

### `new Ensemble.ExtraTreesClassifier(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nEstimators` | `number` | `100` | Number of randomized trees in the ensemble. |
| `bootstrap` | `boolean` | `false` | Whether to fit each tree on a bootstrap sample (defaults to `false` like scikit-learn, using the full dataset with randomized splits). |
| `max_features` | `number \| 'sqrt' \| 'log2' \| 'all'` | `'sqrt'` | Candidate features evaluated per node split. |
| `randomState` | `number` | `undefined` | Seed for deterministic threshold draws and sampling. |
| Tree options | `ExtraTreeClassifier` props | — | Supports depth and split controls such as `max_depth`, `min_samples_split`, and `criterion`. |

### Methods & properties

| Member | Signature | Description |
| --- | --- | --- |
| `fit` | `(X: number[][], y: number[]) => void` | Fits the ensemble and computes averaged `featureImportances`. |
| `predictProba` | `(X: number[][]) => number[][]` | Averages leaf class probability distributions across all trees. |
| `predict` | `(X: number[][]) => number[]` | Returns the highest-probability class per sample. |
| `classes` / `featureImportances` | `number[]` | Sorted class labels and impurity-based feature importances summing to `1`. |

### Extra Trees vs Random Forest

- Try `ExtraTreesClassifier` when you have many noisy continuous features, need `predictProba` and `featureImportances`, or want faster training in browser sessions.
- Pair with [`FeatureSelection.SelectFromModel`](/docs/apis/feature_selection/selectors) to prune low-importance columns automatically.
- **Related pages**: [ExtraTreesRegressor](/docs/apis/ensemble/extraTreesRegressor), [RandomForestClassifier](/docs/apis/ensemble/randomForestClassifier), [ExtraTreeClassifier](/docs/apis/tree/extraTreeClassifier).
