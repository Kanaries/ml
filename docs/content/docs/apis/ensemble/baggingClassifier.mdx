## Algorithm overview

**BaggingClassifier** (Bootstrap Aggregating) trains an ensemble of `nEstimators` classifiers—each fitted on a different random subset of the training rows—and combines their outputs by majority vote. Bagging is specifically designed to reduce **variance** in high-variance, low-bias base learners such as unpruned decision trees, k-nearest neighbors, or small neural models without increasing bias.

Unlike [RandomForestClassifier](/docs/apis/ensemble/randomForestClassifier), which specifically pairs decision trees with per-split feature subsampling, `BaggingClassifier` is a general meta-ensemble: you can bag the default `DecisionTreeClassifier` or wrap any custom classifier via `estimatorFactory`.

## JavaScript implementation

`@kanaries/ml` provides `Ensemble.BaggingClassifier` in pure TypeScript for browser and Node.js runtimes. By default it uses `DecisionTreeClassifier` members with `bootstrap: true` (sampling with replacement) and deterministic `randomState` seeding. Passing `bootstrap: false` switches from bagging to **pasting** (sampling subsets without replacement).

## Quick start example

```ts
import { Ensemble } from '@kanaries/ml';

const clf = new Ensemble.BaggingClassifier({
  nEstimators: 20,
  maxSamples: 3,
  randomState: 12,
});

clf.fit([[0, 0], [0, 1], [3, 3], [4, 3]], [0, 0, 1, 1]);
const pred = clf.predict([[1, 1], [4, 4]]);
console.log(pred);
```

## Detailed API reference

### `new Ensemble.BaggingClassifier(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nEstimators` | `number` | `10` | Number of base classifiers in the ensemble. |
| `maxSamples` | `number` | `X.length` | Samples drawn per estimator (integer count or fraction in `(0, 1]`). |
| `bootstrap` | `boolean` | `true` | Sample with replacement (`true` = bagging) or without replacement (`false` = pasting). |
| `randomState` | `number` | `undefined` | Seed for reproducible subsampling and member seeds. |
| `estimatorFactory` | `(seed?: number) => { fit, predict }` | `DecisionTreeClassifier` | Optional factory returning a fresh base classifier per ensemble member. |

### Methods & usage guidance

- `fit(trainX: number[][], trainY: number[]): void` — draws `nEstimators` sample subsets and fits each member.
- `predict(testX: number[][]): number[]` — predicts by majority vote across all fitted members.
- **When to prefer Random Forest**: If your base estimator is a decision tree and your dataset has many correlated features, [`Ensemble.RandomForestClassifier`](/docs/apis/ensemble/randomForestClassifier) usually outperforms plain bagging by also subsampling features at every split.
- **Related pages**: [BaggingRegressor](/docs/apis/ensemble/baggingRegressor), [RandomForestClassifier](/docs/apis/ensemble/randomForestClassifier), [AdaBoostClassifier](/docs/apis/ensemble/adaboostClassifier).
