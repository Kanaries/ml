## Algorithm overview

**ExtraTreesRegressor** builds an ensemble of extremely randomized [regression trees](/docs/apis/tree/extraTreeRegressor) and averages their numeric outputs. Instead of scanning every candidate cut point to minimize squared error at each node, each tree draws random split thresholds per candidate feature and keeps the best random split.

This extra split randomization frequently produces smoother prediction curves than [RandomForestRegressor](/docs/apis/ensemble/randomForestRegressor) on noisy continuous features while training faster in pure JavaScript—because avoiding full threshold sweeps cuts per-node work dramatically.

## JavaScript implementation

`Ensemble.ExtraTreesRegressor` runs in browsers and Node.js with zero native dependencies, supports deterministic `randomState` seeding, exposes averaged `featureImportances` for feature ranking, composes with [`Pipeline`](/docs/apis/pipeline), and serializes via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Ensemble } from '@kanaries/ml';

const model = new Ensemble.ExtraTreesRegressor({
  nEstimators: 100,
  max_features: 'all',
  randomState: 42,
});
model.fit([[0], [1], [2], [3], [4]], [0, 1, 4, 9, 16]);
console.log(model.predict([[2.5]]), model.featureImportances);
```

## Detailed API reference

### `new Ensemble.ExtraTreesRegressor(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nEstimators` | `number` | `100` | Number of extremely randomized regression trees in the ensemble. |
| `bootstrap` | `boolean` | `false` | Whether each tree trains on a bootstrap sample (`false` trains each tree on all rows with random splits). |
| `max_features` | `number \| 'sqrt' \| 'log2' \| 'all'` | `'all'` | Candidate features evaluated per split. |
| `randomState` | `number` | `undefined` | Seed for reproducible threshold draws. |
| Tree options | `ExtraTreeRegressor` props | — | Supports `max_depth`, `min_samples_split`, and related stopping rules. |

### Methods & properties

- `fit(X: number[][], y: number[]): void` — trains all trees and aggregates `featureImportances`.
- `predict(X: number[][]): number[]` — averages predictions across all trees.
- `featureImportances: number[]` — normalized impurity-reduction importances after fitting.
- **Related pages**: [RandomForestRegressor](/docs/apis/ensemble/randomForestRegressor), [ExtraTreesClassifier](/docs/apis/ensemble/extraTreesClassifier), [ExtraTreeRegressor](/docs/apis/tree/extraTreeRegressor).
