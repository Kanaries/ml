## Algorithm overview

**BaggingRegressor** (Bootstrap Aggregating for regression) fits multiple cloned regressors on independent random subsets of the training data and averages their continuous predictions. Averaging smooths out the sharp variance of unstable base learners—most commonly unpruned [regression trees](/docs/apis/tree/decisionTreeRegressor)—while preserving their flexibility on non-linear curves.

Because `BaggingRegressor` accepts any registered `@kanaries/ml` regressor as its `estimator` prototype, you can also bag ridge regressors, k-nearest-neighbor regressors, or polynomial models to stabilize predictions on noisy datasets.

## JavaScript implementation

`Ensemble.BaggingRegressor` runs in pure TypeScript across browsers and Node.js, clones the base `estimator` cleanly via `BaseEstimator.clone()`, supports deterministic `randomState` seeding, integrates into [`Pipeline`](/docs/apis/pipeline), and serializes with `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Ensemble } from '@kanaries/ml';

const X = [[0], [1], [2], [3], [4]];
const y = [0, 1, 4, 9, 16];
const model = new Ensemble.BaggingRegressor({
  nEstimators: 25,
  maxSamples: 0.8,
  randomState: 42,
});
model.fit(X, y);
console.log(model.predict([[2.5]]));
```

## Detailed API reference

### `new Ensemble.BaggingRegressor(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `estimator` | `RegressorBase` | `DecisionTreeRegressor` | Base regressor prototype cloned once per ensemble member. |
| `nEstimators` | `number` | `10` | Number of bagged regressors averaged during `predict()`. |
| `maxSamples` | `number` | `1.0` | Fraction in `(0, 1]` or integer count of samples drawn per member. |
| `bootstrap` | `boolean` | `true` | Sample rows with replacement (`true`) or without replacement (`false`). |
| `randomState` | `number` | `undefined` | Seed for reproducible resampling. |

### Methods

- `fit(X: number[][], y: number[]): void` — fits `nEstimators` cloned regressors on resampled rows.
- `predict(X: number[][]): number[]` — returns the element-wise mean prediction across all members.
- **Related pages**: [BaggingClassifier](/docs/apis/ensemble/baggingClassifier), [RandomForestRegressor](/docs/apis/ensemble/randomForestRegressor), [ExtraTreesRegressor](/docs/apis/ensemble/extraTreesRegressor).
