## Algorithm overview

**RandomForestRegressor** averages the numeric predictions of an ensemble of randomized [regression trees](/docs/apis/tree/decisionTreeRegressor). While a single regression tree produces blocky step-function predictions that easily overfit noise, averaging dozens of bootstrap-resampled, feature-subsampled trees smooths variance sharply while capturing non-linear curves, thresholds, and interaction effects automatically.

RandomForestRegressor is well suited for:

- Tabular regression where relationships are non-linear or piecewise (pricing, demand forecasting, latency estimation).
- Mixed numeric features without requiring polynomial expansion or feature standardization.
- Robust baseline modeling before investing in gradient boosting hyperparameter sweeps.

Keep one key limitation in mind: because every tree outputs averages of observed training targets in its leaves, Random Forests **cannot extrapolate** linear trends beyond the numeric range of `y` seen during `fit()`. For trend extrapolation, combine linear features with [Ridge](/docs/apis/linear/ridgeRegression) or [Polynomial Regression](/docs/apis/linear/polynomialRegression).

## JavaScript implementation

`@kanaries/ml` exposes `Ensemble.RandomForestRegressor` in pure TypeScript for browsers and Node.js. It supports bootstrap resampling, `maxFeatures` subsampling, deterministic `randomState` seeding, [`Pipeline`](/docs/apis/pipeline) composition, and JSON persistence via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Ensemble } from '@kanaries/ml';

const reg = new Ensemble.RandomForestRegressor({
  nEstimators: 25,
  maxDepth: 4,
  randomState: 7,
});

reg.fit([[0], [1], [2], [3]], [0, 1, 4, 9]);
const pred = reg.predict([[2.5]]);
console.log(pred);
```

## Detailed API reference

### `new Ensemble.RandomForestRegressor(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nEstimators` | `number` | `100` | Number of regression trees averaged in the ensemble. |
| `bootstrap` | `boolean` | `true` | Sample training rows with replacement for each tree. |
| `maxDepth` | `number` | `undefined` | Maximum depth per tree; capping to `4`–`10` curbs overfitting and keeps browser inference fast. |
| `minSamplesSplit` | `number` | `2` | Minimum samples required in a node before attempting another split. |
| `maxFeatures` | `number \| 'sqrt' \| 'log2'` | `1.0` | Features considered per split (`1.0` considers all features; `'sqrt'` reduces tree correlation on wide datasets). |
| `randomState` | `number` | `undefined` | Seed for reproducible forest construction. |

### Methods

| Method | Signature | Description |
| --- | --- | --- |
| `fit` | `(trainX: number[][], trainY: number[]) => void` | Fits all regression trees on `(trainX, trainY)`. |
| `predict` | `(testX: number[][]) => number[]` | Returns the mean prediction across all trees for each sample. |
| `score` / `toJSON` / `clone` | Inherited from `RegressorBase` | Computes R² score and supports JSON model serialization. |
