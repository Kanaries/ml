## Algorithm overview

**RandomForestClassifier** is a bagging ensemble of independent [decision trees](/docs/apis/tree/decisionTreeClassifier) that predicts class labels by aggregating votes across the forest. Each tree is trained on a bootstrap resample of the rows (`bootstrap: true`) and considers only a random subset of candidate features (`maxFeatures`, defaulting to `'sqrt'`) at every split.

That double randomization decorrelates individual trees so their variance averages out while preserving the ability to model non-linear interactions, mixed feature scales, and multiclass decision boundaries—making Random Forest one of the most reliable out-of-the-box tabular classifiers with minimal preprocessing.

Use RandomForestClassifier when:

- Linear boundaries underfit non-linear feature interactions.
- A single decision tree overfits noise or fluctuates across train/test splits.
- Features sit on wildly different numeric scales (trees are invariant to monotonic feature scaling).

## JavaScript implementation

`@kanaries/ml` provides `Ensemble.RandomForestClassifier` in pure TypeScript for browsers and Node.js. It builds `DecisionTreeClassifier` estimators with deterministic `randomState` seeding, integrates cleanly inside [`Pipeline`](/docs/apis/pipeline) and [`Calibration.CalibratedClassifierCV`](/docs/apis/calibration), and persists trained forests as JSON via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

For interactive browser apps, keep `nEstimators` between `20` and `100` and cap `max_depth` (for example `6`–`12`) to keep training sub-second and serialized JSON payloads compact. You can also explore how tree depth and ensemble size shape decision boundaries in the [Random Forest Playground](/playground/random-forest).

## Quick start example

```ts
import { Ensemble } from '@kanaries/ml';

const clf = new Ensemble.RandomForestClassifier({
  nEstimators: 25,
  maxFeatures: 'sqrt',
  randomState: 42,
});

clf.fit([[0, 0], [0, 1], [3, 3], [4, 3]], [0, 0, 1, 1]);
const pred = clf.predict([[1, 1], [4, 4]]);
console.log(pred);
```

## Detailed API reference

### `new Ensemble.RandomForestClassifier(props?)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `nEstimators` | `number` | `100` | Number of trees in the forest. Larger values reduce variance at linear training/inference cost. |
| `bootstrap` | `boolean` | `true` | Whether each tree trains on a bootstrap sample drawn with replacement. |
| `maxFeatures` | `number \| 'sqrt' \| 'log2'` | `'sqrt'` | Number of features evaluated at each split (`'sqrt'` = `sqrt(nFeatures)`, `'log2'` = `log2(nFeatures)`, fraction in `(0, 1]`, or explicit integer). |
| `randomState` | `number` | `undefined` | Seed for reproducible bootstrap draws and feature subsampling. |
| Tree options | `DecisionTreeClassifier` props | — | Forwarded to every member tree (`criterion`, `max_depth`, `min_samples_split`, `min_samples_leaf`). |

### Methods

| Method | Signature | Description |
| --- | --- | --- |
| `fit` | `(trainX: number[][], trainY: number[]) => void` | Fits `nEstimators` randomized decision trees on `(trainX, trainY)`. |
| `predict` | `(testX: number[][]) => number[]` | Returns majority-vote class predictions for each row in `testX`. |
| `getParams` / `setParams` / `clone` / `toJSON` | Inherited from `ClassifierBase` | Full estimator contract & JSON serialization. |

### Tuning & comparison tips

- **Overfitting or huge JSON models**: Restrict `max_depth` (`5`–`12`) or raise `min_samples_leaf` before increasing `nEstimators`.
- **Faster randomized alternative**: Compare against [`Ensemble.ExtraTreesClassifier`](/docs/apis/ensemble/extraTreesClassifier), which samples split thresholds randomly and often trains faster in JavaScript.
- **Higher accuracy on tabular benchmarks**: Try [`Ensemble.GradientBoostingClassifier`](/docs/apis/ensemble/gradientBoostingClassifier) or [`Ensemble.XGBoostClassifier`](/docs/apis/ensemble/xgboostClassifier).
