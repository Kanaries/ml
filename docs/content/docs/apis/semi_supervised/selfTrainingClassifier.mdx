## Algorithm overview

In many real-world applications—support ticket tagging, anomaly triage, document classification—labeling thousands of rows is expensive while unlabeled data is abundant. **Self-Training** turns any supervised classifier that emits class probabilities (`predictProba`) into a **semi-supervised learner**:

1. Fit the base classifier on the initially labeled rows (every row whose target `y[i] !== -1`).
2. Score all remaining unlabeled rows (`y[i] === -1`) with `predictProba()`.
3. Promote the most confident unlabeled predictions into pseudo-labels (either all rows exceeding `threshold` or the top `kBest` rows) and refit.
4. Repeat until no unlabeled rows qualify, all rows are labeled, or `maxIter` rounds finish.

Self-training works best when your base classifier's probabilities are reasonably calibrated—consider wrapping uncalibrated models with [`Calibration.CalibratedClassifierCV`](/docs/apis/calibration) or choosing probabilistic learners like [`Bayes.GaussianNB`](/docs/apis/bayes/gaussianNB) or [`Linear.LogisticRegression`](/docs/apis/linear/logisticRegression).

## JavaScript implementation

`SemiSupervised.SelfTrainingClassifier` wraps any registered `@kanaries/ml` classifier exposing `predictProba()` in pure TypeScript for browser and Node.js workflows. Unlabeled targets follow scikit-learn's `-1` sentinel convention, and the fitted meta-estimator serializes cleanly via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { Bayes, SemiSupervised } from '@kanaries/ml';

const model = new SemiSupervised.SelfTrainingClassifier({
  estimator: new Bayes.GaussianNB(),
  threshold: 0.8,
  maxIter: 10,
});
model.fit([[-3], [-2], [-1], [1], [2], [3]], [0, 0, -1, -1, 1, 1]);
console.log({
  transduction: model.transduction,
  termination: model.terminationCondition,
});
```

## Detailed API reference

### `new SemiSupervised.SelfTrainingClassifier(props)`

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `estimator` | `ClassifierBase` | *required* | Any registered classifier implementing `fit()`, `predict()`, and `predictProba()`. |
| `criterion` | `'threshold' \| 'kBest'` | `'threshold'` | Selection policy for promoting unlabeled rows to pseudo-labels. |
| `threshold` | `number` | `0.75` | Minimum maximum-class probability required when `criterion: 'threshold'`. |
| `kBest` | `number` | `10` | Maximum rows promoted per iteration when `criterion: 'kBest'`. |
| `maxIter` | `number` | `10` | Maximum self-training rounds. |

### Methods & fitted properties

- `fit(X, y)` / `predict(X)` / `predictProba(X)` — trains semi-supervised model (`-1` marks unlabeled rows) and predicts labels or probabilities.
- Properties: `transduction` (final labels including pseudo-labels; remaining unlabeled stay `-1`), `labeledIteration` (`0` for original seed labels, `1..nIter` for pseudo-labeled rows, `-1` if unlabeled), `nIter`, and `terminationCondition`.
