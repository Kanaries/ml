## Algorithm overview

**Univariate feature scoring** evaluates each feature column independently against the target vector `y` without training a full predictive model. Because every column is scored in isolation, univariate tests run in milliseconds and make an ideal first-pass diagnostic for spotting strong signals, zero-variance columns, and non-linear relationships before building pipelines.

Choose the right statistical test for your feature and target types:

| Function | Target type | Feature type | Detects |
| --- | --- | --- | --- |
| `chi2(X, y)` | Classification | Non-negative counts / frequencies | Dependence between counts and class labels |
| `fClassif(X, y)` | Classification | Continuous numeric | Linear mean differences across classes (ANOVA F) |
| `mutualInfoClassif(X, y)` | Classification | Discrete or continuous | Arbitrary linear & non-linear statistical dependence |
| `mutualInfoRegression(X, y)` | Regression | Discrete or continuous | Arbitrary non-linear dependence with numeric `y` |

## JavaScript implementation

`@kanaries/ml` provides all four scikit-learn-compatible functions under `import { FeatureSelection } from '@kanaries/ml'` in pure TypeScript for browser and Node.js apps. Mutual-information estimators implement Ross / Kraskov k-nearest-neighbor entropy estimation with optional seeded jitter (`randomState`) to break ties reproducibly on repeated continuous values.

## Quick start example

```ts
import { FeatureSelection } from '@kanaries/ml';

const X = [[0, 1], [1, 0], [5, 1], [6, 0]];
const y = [0, 0, 1, 1];
const [fScores, pValues] = FeatureSelection.fClassif(X, y);
const information = FeatureSelection.mutualInfoClassif(X, y, { randomState: 42 });
console.log({ fScores, pValues, information });
```

## Detailed API reference

- **`FeatureSelection.chi2(X, y)`** → `[scores: number[], pValues: number[]]` — requires strictly non-negative features (`X[i][j] >= 0`).
- **`FeatureSelection.fClassif(X, y)`** → `[scores: number[], pValues: number[]]` — computes one-way ANOVA F-statistics and exact p-values per column.
- **`FeatureSelection.mutualInfoClassif(X, y, options?)`** / **`mutualInfoRegression(X, y, options?)`** → `number[]` (non-negative nats per feature).
  - `discreteFeatures?: boolean | boolean[]` (default `false`) — treat all or specific columns as discrete counts.
  - `nNeighbors?: number` (default `3`) — k-NN neighborhood size controlling bias/variance of entropy estimation.
  - `randomState?: number` — seed for deterministic tie-breaking noise on continuous features.
