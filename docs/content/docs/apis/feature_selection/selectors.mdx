## Algorithm overview

Unlike univariate filters that inspect one feature in isolation, **model-based and recursive feature selectors** evaluate features jointly using a supervised estimator's learned `featureImportances` or linear `coef` weights:

- **`SelectFromModel`**: fits the estimator once and retains all features whose importance meets or exceeds `threshold` (a fixed cutoff, `'mean'`, `'median'`, or scaled expression like `'1.25*median'`). Fast and ideal inside a [`Pipeline`](/docs/apis/pipeline).
- **`RFE` (Recursive Feature Elimination)**: fits the estimator, drops the weakest `step` features, and repeats until exactly `nFeaturesToSelect` remain—capturing interactions that change once redundant features are pruned.
- **`RFECV`**: runs cross-validated RFE across candidate subset sizes (`minFeaturesToSelect..nFeatures`) and automatically keeps the subset count maximizing CV score.

## JavaScript implementation

`FeatureSelection.SelectFromModel`, `FeatureSelection.RFE`, and `FeatureSelection.RFECV` run in pure TypeScript across browsers and Node.js. Each selector clones its prototype `estimator` safely without mutating it, supports `transform()` for seamless [`Pipeline`](/docs/apis/pipeline) integration, and serializes cleanly via `toJSON()` / [`loadModel()`](/docs/apis/serialization).

## Quick start example

```ts
import { FeatureSelection, Tree } from '@kanaries/ml';

const X = [[0, 1, 9], [1, 0, 9], [8, 1, 9], [9, 0, 9]];
const y = [0, 0, 1, 1];
const selector = new FeatureSelection.RFE({
  estimator: new Tree.DecisionTreeClassifier({ randomState: 42 }),
  nFeaturesToSelect: 1,
});
selector.fit(X, y);
console.log(selector.getSupport(true), selector.transform(X));
```

## Detailed API reference

| Class | Options | Key methods & properties |
| --- | --- | --- |
| `SelectFromModel` | `estimator`, `threshold?` (number, `'mean'`, `'median'`, `'k*mean'`, `'k*median'`), `maxFeatures?` | `fit`, `transform`, `getSupport(indices?)`, `fittedEstimator` |
| `RFE` | `estimator`, `nFeaturesToSelect?` (int or fraction), `step?` (int or fraction) | `fit`, `transform`, `predict`, `score`, `getSupport(indices?)`, `ranking` |
| `RFECV` | `estimator`, `minFeaturesToSelect?`, `step?`, `cv?`, `scoring?` | Same as `RFE`, plus `gridScores` and `cvResults` (`nFeatures`, `meanTestScore`) |

- **Tip**: Use [`Linear.LassoRegression`](/docs/apis/linear/lassoRegression), [`Linear.RidgeRegression`](/docs/apis/linear/ridgeRegression), [`Tree.DecisionTreeClassifier`](/docs/apis/tree/decisionTreeClassifier), or [`Ensemble.ExtraTreesClassifier`](/docs/apis/ensemble/extraTreesClassifier) as base estimators since all declare `coef` or `featureImportances`.
